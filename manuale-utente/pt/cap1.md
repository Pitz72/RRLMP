# CAPÍTULO 1: INTRODUÇÃO E CONFIGURAÇÃO

Bem-vindo ao **Runtime Live Machine**.
Este capítulo irá guiá-lo através dos primeiros passos: desde a compreensão da filosofia do software até ao primeiro arranque.

## 1.1 O que é o Runtime Live Machine (RLM)

**Runtime Live Machine** é uma arquitetura de áudio profissional concebida para a direção de **espetáculos ao vivo individuais**, podcasts, eventos e rádios web.

Ao contrário do complexo software de automação de rádio 24/7 (que reproduz música em rotação durante dias), o RLM é uma ferramenta de **Performance**. Foi concebido para ser "tocado" em tempo real por um realizador ou locutor.

### Porquê escolher o RLM?
*   **Filosofia "Single Show"**: Cada projeto é um contentor isolado que guarda tudo o que é necessário para esse episódio ou evento específico.
*   **Motor de Áudio Nativo**: Utiliza a tecnologia *Direct Disk Streaming* para reproduzir ficheiros de áudio (WAV, MP3) instantaneamente sem carregá-los na RAM, garantindo uma estabilidade absoluta.
*   **Segurança Total**: Inclui sistemas de Auto-Backup e avisos de "Dead Air" para evitar o silêncio no ar.
*   **Controlo Físico**: Suporta nativamente controladores MIDI e teclados para uma direção tátil.

## 1.2 Instalação

### Requisitos do Sistema
*   **Windows**: Windows 10 ou Windows 11 (64-bit).
*   **macOS**: macOS 11 (Big Sur) ou posteriores (Suporte Apple Silicon & Intel).
*   **RAM**: Mínimo 4GB (8GB Recomendados).
*   **Espaço em Disco**: 200MB para a aplicação + espaço para os seus ficheiros de áudio.

### Instalação no Windows
1.  Descarregue o ficheiro Runtime Live Machine Setup 1.0.0.exe do site oficial.
2.  Faça duplo clique no executável.
3.  O instalador automático copiará os ficheiros e criará um atalho no Ambiente de Trabalho.
4.  Ao terminar, a aplicação iniciará automaticamente.

> **Nota de Segurança**: Como o software é atualizado frequentemente, o Windows SmartScreen pode mostrar um aviso "PC protegido pelo Windows". Clique em **"Mais informações"** e depois em **"Executar mesmo assim"**. O software é seguro e livre de malware.

### Instalação no macOS
1.  Descarregue o ficheiro .dmg.
2.  Abra o ficheiro de imagem.
3.  Arraste o ícone do **Runtime Live Machine** para a pasta **Aplicações**.
4.  No primeiro arranque, poderá ter de autorizar a aplicação em *Preferências do Sistema > Segurança e Privacidade* se não provier da App Store.

## 1.3 O Ecrã de Boas-vindas (Welcome Screen)

No primeiro arranque, será recebido pelo **Welcome Screen**. Este é o seu painel de início, concebido para permitir que comece a trabalhar em segundos.

### Elementos do Ecrã
1.  **Estado da Versão**: Sob o logótipo, verá o número da versão atual (ex. 1.0.0).
    *   ✅ **Verde**: Tem a última versão disponível.
    *   ⬇️ **Amarelo/Laranja**: Está disponível uma atualização. O sistema verifica automaticamente os servidores no arranque.
2.  **Seletor de Idioma**: No canto superior direito (ou no menu dedicado) encontrará bandeiras para alterar o idioma da interface.
    *   *Idiomas suportados*: Inglês (Predefinido), Italiano, Francês, Alemão, Espanhol, Português, Russo, Chinês.
    *   A sua escolha será guardada para futuros arranques.

### Ações Disponíveis
*   **Novo Projeto (New Project)**: Cria uma sessão vazia. Todas as colunas estarão limpas e prontas a ser preenchidas. Use isto para começar um novo episódio do zero.
*   **Carregar Projeto (Load Project)**: Abre uma caixa de diálogo para selecionar um ficheiro .lmp (Live Machine Project) do seu disco.
    *   *Dica*: Os ficheiros .lmp contêm todas as definições dos clips, volumes, cores e mapeamentos MIDI.
*   **Manual Online**: Abre este manual no seu navegador predefinido para uma consulta rápida.

> **Primeiro Arranque**: Assim que clicar em "Novo Projeto" ou carregar um ficheiro, a interface abrir-se-á em ecrã inteiro para maximizar o espaço de trabalho. Está pronto para ir para o ar.
