# 第 1 章：简介与设置

欢迎使用 **Runtime Live Machine Pro (RRLMP)**。
本章将引导您完成第一步：从了解软件理念到首次启动。

## 1.1 什么是 Runtime Live Machine Pro (RRLMP)

**Runtime Live Machine Pro** 是一款专业的“Pro 级”音频架构，专为**单场现场表演**、播客、活动和网络广播的导播而设计。

与复杂的 24/7 全天候电台自动化软件（连续数天循环播放音乐）不同，RRLMP 是一款**表演**工具。它专为导演或播音员实时“演奏”而设计，可对每一次转场进行精准控制。

### 为什么选择 RRLMP？
*   **“单场秀”理念**：每个项目都是一个独立的容器，包含该特定剧集或活动所需的一切。
*   **Main-Side-Heavy 架构**：使用 Node.js 代理进行繁重的音频解码 (FFmpeg)，确保即使处理大型 WAV 文件，界面 (Renderer) 也能保持流畅且不崩溃。
*   **全面安全**：包含自动备份系统、.lmp 文件完整性检查以及 Intro/Outro 提示点的视觉警告。
*   **物理控制**：原生支持 MIDI 控制器（具有 MIDI Learn 功能）和键盘，实现触感敏捷的导播。

## 1.2 安装

### 系统要求
*   **Windows**：Windows 10 或 Windows 11（64 位）。
*   **macOS**：macOS 11 (Big Sur) 或更高版本（原生支持 Apple Silicon 和 Intel）。
*   **Linux**：支持 AppImage 和 .deb 软件包（Ubuntu/Debian/Mint）。
*   **内存**：至少 4GB（建议 8GB）。
*   **磁盘空间**：200MB 用于应用程序 + 您的音频文件所需空间。

### Windows 安装
1.  从官方网站或代码仓库下载 `Runtime Live Machine Pro Setup 1.0.0.exe` 文件。
2.  双击可执行文件。
3.  自动安装程序将复制文件并在桌面上创建快捷方式。
4.  完成后，应用程序将自动启动。

> **安全提示**：由于软件更新频繁，Windows SmartScreen 可能会显示“Windows 已保护您的电脑”警告。点击 **“更多信息”**，然后点击 **“仍要运行”**。该软件是安全且经过签名的，不含恶意软件。

### macOS 安装
1.  下载 `.dmg` 文件。
2.  打开镜像文件，将 **Runtime Live Machine Pro** 图标拖入 **Applications**（应用程序）文件夹。
3.  首次启动时，您可能需要在 *系统设置 > 安全性与隐私* 中授权该应用程序。

## 1.3 欢迎屏幕 (Welcome Screen)

首次启动时，您将看到采用横向布局的新版 **Welcome Screen**。这是您的起始仪表板，旨在让您在几秒钟内开始工作。

### 屏幕元素
1.  **新徽标**：Pro 徽标（5 个 VU 表栏和播放三角形）代表软件的稳定版本。
2.  **版本状态**：在徽标下方，您将看到当前版本号（例如 `v1.0.0`）。
    *   ✅ **绿色**：您拥有最新版本。
    *   ⬇️ **黄色/橙色**：有可用更新。
3.  **语言选择器**：在右上角，您可以找到国旗图标（支持 8 种语言），点击可立即更改界面语言。
    *   *语言*：IT, EN, FR, DE, ES, PT, RU, ZH。
    *   您的选择将保存在用户配置文件中。

### 可用操作
*   **新建项目 (New Project)**：创建一个空会话。所有 5 个列（素材、音乐、人声、音效、开场前）都将准备好加载文件。
*   **加载项目 (Load Project)**：打开现有的 `.lmp` 文件。RRLMP 将执行完整性检查：如果缺少任何音频文件，它们将以红色突出显示。
*   **在线手册**：在您的浏览器中打开最新的文档。

> **首次启动**：RRLMP 优先以全屏模式启动。加载项目后，您会注意到页头中的青色 **PRO** 徽标，这确认了许可证状态和音频引擎的稳定性。
