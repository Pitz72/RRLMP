# 第1章：简介与设置

欢迎使用 **Runtime Live Machine**。
本章将引导您完成第一步：从了解软件理念到首次启动。

## 1.1 什么是 Runtime Live Machine (RLM)

**Runtime Live Machine** 是一个专业的音频架构，专为**单场现场表演**、播客、活动和网络广播的导播而设计。

与复杂的24/7全天候电台自动化软件（连续数天循环播放音乐）不同，RLM 是一个**表演**工具。它专为导演或播音员实时“演奏”而设计。

### 为什么选择 RLM？
*   **“单场秀”理念**：每个项目都是一个独立的容器，包含该特定剧集或活动所需的一切。
*   **原生音频引擎**：使用 *Direct Disk Streaming*（直接磁盘流）技术即时播放音频文件（WAV, MP3），无需将其加载到内存中，确保绝对稳定性。
*   **全面安全**：包含自动备份系统和“死机”警告，以避免直播中出现静音。
*   **物理控制**：原生支持 MIDI 控制器和键盘，实现触觉导播。

## 1.2 安装

### 系统要求
*   **Windows**：Windows 10 或 Windows 11（64位）。
*   **macOS**：macOS 11 (Big Sur) 或更高版本（支持 Apple Silicon 和 Intel）。
*   **内存**：至少 4GB（建议 8GB）。
*   **磁盘空间**：200MB 用于应用程序 + 您的音频文件所需空间。

### Windows 安装
1.  从官方网站下载 Runtime Live Machine Setup 1.0.0.exe 文件。
2.  双击可执行文件。
3.  自动安装程序将复制文件并在桌面上创建快捷方式。
4.  完成后，应用程序将自动启动。

> **安全提示**：由于软件更新频繁，Windows SmartScreen 可能会显示“Windows 已保护您的电脑”警告。点击 **“更多信息”**，然后点击 **“仍要运行”**。该软件是安全的，不含恶意软件。

### macOS 安装
1.  下载 .dmg 文件。
2.  打开镜像文件。
3.  将 **Runtime Live Machine** 图标拖入 **Applications**（应用程序）文件夹。
4.  首次启动时，如果您不是从 App Store 获取的，可能需要在 *系统偏好设置 > 安全性与隐私* 中授权该应用程序。

## 1.3 欢迎屏幕 (Welcome Screen)

首次启动时，您将看到 **Welcome Screen**。这是您的起始仪表板，旨在让您在几秒钟内开始工作。

### 屏幕元素
1.  **版本状态**：在徽标下方，您将看到当前版本号（例如 1.0.0）。
    *   ✅ **绿色**：您拥有最新版本。
    *   ⬇️ **黄色/橙色**：有可用更新。系统在启动时会自动检查服务器。
2.  **语言选择器**：在右上角（或专用菜单中），您可以找到用于更改界面语言的旗帜。
    *   *支持的语言*：英语（默认）、意大利语、法语、德语、西班牙语、葡萄牙语、俄语、中文。
    *   您的选择将被保存以供将来启动使用。

### 可用操作
*   **新建项目 (New Project)**：创建一个空会话。所有列都将是空的，准备填充。使用此选项从头开始新剧集。
*   **加载项目 (Load Project)**：打开一个对话框，从您的磁盘中选择一个 .lmp (Live Machine Project) 文件。
    *   *提示*：.lmp 文件包含所有剪辑设置、音量、颜色和 MIDI 映射。
*   **在线手册**：在您的默认浏览器中打开本手册以便快速参考。

> **首次启动**：一旦您点击“新建项目”或加载文件，界面将全屏打开以最大化工作空间。您已准备好开始直播。
