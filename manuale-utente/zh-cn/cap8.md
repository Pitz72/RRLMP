# 第8章：故障排除与常见问题解答 (FAQ)

即使在最稳定的软件中，也可能由于硬件或操作系统而发生意外事件。在这里，您将找到最常见问题的解决方案。

---

## 8.1 音频问题

### 计时器在运行，VU 表在移动，但我什么也听不到。
软件正在正确播放音频（您可以从顶部的彩色条看到），但信号未到达您的扬声器/耳机。
1.  **检查总音量 (Master Volume)**：确保顶部的音量滑块不为零。
2.  **验证输出 (路由)**：
    *   点击 **齿轮** (设置) 图标。
    *   检查在“音频输出设备 (Audio Output Device)”中选择了哪个设备。
    *   有时，如果 USB 设备被拔出并重新插入，Windows 会更改其 ID。尝试从列表中重新选择您的声卡（例如 *Rødecaster Pro* 或 *耳机*）。
3.  **外部混音器**：如果您输出到 USB 混音器，请检查该通道的物理推子是否未降低或处于“静音 (Mute)”状态。

### 音频“噼啪作响”或跳跃。
由于原生引擎，这很少发生，但如果计算机的 CPU 处于极端压力下，则可能会发生这种情况。
*   关闭其他繁重的应用程序（视频编辑、游戏）。
*   如果您使用专业声卡，请检查声卡驱动程序中的 *缓冲区大小 (Buffer Size)* 是否过低（建议：256 或 512 采样）。

## 8.2 文件管理与红色剪辑

### 一个剪辑变成了红色并且不再播放。
**红牌**表示软件无法再在磁盘上找到音频文件。
*   **原因**：您移动、重命名或删除了原始 MP3/WAV 文件。或者文件位于现已断开连接的 USB 驱动器/外部磁盘上。
*   **解决方案**：
    1.  重新连接外部磁盘。
    2.  将文件移回其原始位置。
    3.  或者，将文件拖回网格中（创建一个新卡片）并删除旧的红色卡片。

> **预防**：为了避免此问题，请使用 **导出包 (Export Package)** 功能（第 7 章），该功能会将所有文件连同项目一起复制到一个安全文件夹中。

## 8.3 MIDI 问题

### 我的 MIDI 控制器不工作 / 未被检测到。
1.  **MIDI 黄金法则**：在启动 Runtime Live Machine **之前**，控制器必须连接到计算机。
    *   如果在软件打开时连接它，内部浏览器可能无法看到它。关闭并重新打开 RLM。
2.  **学习模式 (Learn Mode)**：检查您是否未让“MIDI 学习”模式处于活动状态（青色图标）。在此模式下，按键仅用于映射，而不用于播放。
3.  **驱动程序**：一些高级控制器需要特定的驱动程序。验证 Windows 是否正确识别它。

## 8.4 常见问题解答 (FAQ)

**问：我可以使用 RLM 实现 24/7 全天候广播自动化吗？**
答：不能。RLM 专为 *现场* 导播（有人值守的节目）而设计。它没有每小时调度或无限自动音乐轮换功能。

**问：支持哪些音频格式？**
答：它原生支持 **MP3, WAV, AAC, OGG, FLAC**。我们建议使用 WAV 以获得最高质量，或使用 MP3 320kbps 以节省空间。

**问：软件可以在 iPad 或 Android 上运行吗？**
答：不能，Runtime Live Machine 是用于 **Windows** 和 **macOS** 的专业桌面软件。它需要真实计算机的文件管理能力。

**问：如何更新软件？**
答：在启动时，如果有新版本可用（黄色/橙色指示器），欢迎屏幕会通知您。访问官方网站下载更新的安装程序。您保存的 .lmp 项目将与新版本兼容。

**问：在哪里可以找到自动保存文件？**
答：如果您正在处理已保存的文件，.bak 备份位于与项目相同的文件夹中。如果您正在处理一个“无标题”项目并且 PC 关闭，请检查系统应用程序数据文件夹（在 Windows 上：%APPDATA%\runtime-live-machine\）。
