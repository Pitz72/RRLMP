# 第 8 章 — 硬件、键盘与 MIDI

---

Runtime Live Machine Pro 的设计意在与演播室中现有的硬件集成，无需繁琐的配置。本章描述如何引导音频输出、如何将电脑键盘当作控制器使用，以及如何连接物理 MIDI 设备以获得对导播的触感式掌控。

---

## 8.1 音频路由

### 选择输出设备

默认情况下，RLMP 从操作系统的默认音频设备输出。在配有 USB 混音器、外置声卡或多轨系统的专业或半专业环境中，明确指定信号去向很有用。

1. 从工具菜单打开**设置**。
2. 在 *Audio & Mix* 标签页中，打开输出设备菜单：你会看到系统上可用音频设备的列表。
3. 选择想要的设备。

若所选设备被断开，RLMP 会自动回退到系统设备；应用会监测连接，并对 USB 设备的插入或移除作出反应。

### USB 混音器与多通道设置

Rødecaster Pro、RØDECaster Duo 或 Focusrite Scarlett 这类 USB 混音器，通常会向操作系统暴露多个 USB 通道（Main Mix、Sounds/Chat、Monitor 等）。RLMP 表现为单一的立体声源；把它引导到哪个 USB 通道，由你决定。

**USB 混音器的推荐设置。** 把 RLMP 分配到混音器的一个副通道（例如 Rødecaster Pro 上的「Sounds」），而非主通道。这样你就能用一个专用的物理推子控制 RLMP 的音量，把它与物理麦克风的信号分开，并只对该通道施加可能需要的硬件处理。

### 延迟与缓冲

RLMP 使用操作系统的原生音频 API。输出延迟由音频设备的缓冲决定，而非软件。配合专业声卡时，延迟在几毫秒的量级，在播出场景中无法察觉。

若你注意到音频杂音（爆音、dropout），设备的缓冲值很可能过低。请从声卡的控制面板中调高它（而非从 RLMP，它并不直接管理驱动）：256 或 512 采样的缓冲，是延迟与稳定之间的理想平衡点。

## 8.2 键盘控制

电脑键盘是直播中可用的最快控制器：它不需要手眼协调，在黑暗中也能用，且始终触手可及。RLMP 提供一组全局快捷键，以及为单个片段分配按键的能力。

### 全局快捷键

| 按键 | 动作 |
|---|---|
| **Esc** | STOP ALL — 停止所有活动片段 |
| **Canc / Backspace** | 删除选中的片段 |
| **Ctrl+Z** | 撤销对播出单的上一次修改 |
| **Ctrl+Y**（或 **Ctrl+Shift+Z**） | 重做已撤销的修改 |
| **Ctrl+Shift+D** | 显示/隐藏 Debug Overlay |
| **Ctrl+Shift+M** | 打开 MIDI 模拟器（用于无控制器时的测试） |

当 RLMP 为活动窗口时，`Esc` 作为 STOP ALL 生效，即使光标在文本框中也是如此。它不再是注册到操作系统层面的快捷键：若应用在后台，请先把窗口切回前台。

> **注意。** 不存在预先分配给列触发的功能键（F1–F5）。若要快速触发某个特定片段，请为它分配一个专用按键，如下所述。

### 单个片段的自定义按键

除全局快捷键外，每个片段都可以有一个专用按键。对应的徽标会出现在卡片上。

**分配按键的步骤：**
1. 打开片段设置（在卡片上右键），或从工具菜单打开 **Keybinds** 窗口。
2. 点击按键字段。
3. 按下想要的按键。

**可用按键。** 几乎任意按键：字母（A–Z）、数字（0–9）、数字小键盘、空格键、空闲的功能键。若该按键已分配给另一个片段，软件会在覆盖之前提示冲突，这样你就不会制造出看不见的重复。

**输入时的安全保护。** 当你处于文本输入模式（正在重命名片段或写备注）时，自定义按键会被自动禁用。这可防止你打字时误触发。

## 8.3 MIDI 控制器

MIDI 是获得物理、触感、可靠掌控的专业之选。RLMP 支持 USB-MIDI 控制器：键盘、pad（如 Novation Launchpad）、推子控制器（如 Korg nanoKONTROL2）、混合式控制面。

### 连接

将 USB 控制器连接到电脑，然后启动 RLMP。软件通过系统的 Web MIDI API 检测设备，并实时识别控制器的连接与断开。多数 USB-MIDI 控制器是 *class-compliant* 的，无需驱动；对于带专有驱动的专业控制面，请在连接设备之前先安装驱动。

### MIDI Learn

RLMP 不要求你知道 MIDI 音符的编号，也不要求手动配置消息。学习通过 **MIDI Learn** 模式完成，从工具菜单（或 Keybinds 窗口）进入。

**将片段映射到某个键/pad 的步骤：**
1. 启用 MIDI Learn。卡片进入等待状态。
2. 选择要映射的片段（或 pad FX 的格子）。
3. 在控制器上弹奏那个音符、按下那个 pad 或键。带音符编号的 `M` 徽标会出现在卡片上。

**映射全局功能的步骤：**
- 选中 **STOP ALL**，然后在控制器上按一个键：那个键将执行 Stop All。
- 选中**主音量**，然后移动一个推子或旋钮：那个控制将连续地管理主音量。

完成后，停用 MIDI Learn 以回到操作模式。

### 支持的消息类型

**Note On** — 由按钮、pad 和键产生的消息。适合触发片段与全局动作；RLMP 响应按键按下并识别所有 MIDI 通道。Note Off 消息会被忽略。

**Control Change（CC）** — 由推子和电位器产生的消息，带 0 到 127 的连续值。适合主音量：一个映射到 master 的物理推子，提供对输出电平最自然的掌控。

### 映射的可移植性

**片段**的 MIDI 映射保存在 `.lmp` 项目文件中：将项目带到另一台配有相同控制器的电脑，映射无需重新配置即可工作。而**全局功能**（Stop All、主音量）的映射则与电脑绑定，保存在应用的本地偏好中，对那台机器上的所有项目都有效。
