# 第5章：混音引擎 (大脑)

Runtime Live Machine 不是一个随机播放音频文件的简单播放器。在它的内部，有一个始终处于活动状态的 **混音“大脑”**。
该软件就像一个隐形的虚拟音响工程师：它监听您正在做什么，并自动调整其他轨道的音量，以确保最终结果始终干净且清晰易懂。

您不必担心在采访开始时手动降低音乐音量：RLM 会为您处理。

---

## 5.1 音频层级 (金字塔)

要了解它是如何工作的，请将这些列想象成一个重要性金字塔。谁在顶端，就“命令”谁在下面的音量。

1.  **第 1 级 (最高首领)：人声 / 预录 (VOICES / PRERECORDED)** (橙色列)
    *   它们始终拥有绝对优先级。没有人可以降低它们的音量。当它们说话时，其他所有人都安静下来。
2.  **第 2 级 (中产阶级)：剧集歌曲 (EPISODE SONGS)** (红色列)
    *   它们被人声降低。但它们命令资产。
3.  **第 3 级 (背景)：节目资产 (SHOW ASSETS)** (绿色列)
    *   这些是垫乐和声音地毯。它们被几乎所有其他东西静音。

> **注意**：**音效 / 墙 (SFX / CARTWALL)** 列 (灰色) 是“在系统之外”的。音效始终以最大音量播放，并叠加在所有内容之上，而不影响他人或受他人影响。掌声必须听起来很大声，即使是在人声之上。

---

## 5.2 自动闪避 (广播效果)

这是广播中最常用的功能。“闪避 (Ducking)”是指当有人说话时自动降低音乐音量。

*   **它是如何工作的**：
    1.  您有一首歌曲或垫乐正在播放 (音量 100%)。
    2.  您从 **人声 (VOICES)** 列启动一个剪辑（例如，采访或语音消息）。
    3.  软件立即平滑地将歌曲/垫乐降低到背景水平（约 20% 音量，或 -14dB）。
    4.  人声在音乐之上清晰可闻。
    5.  人声剪辑一结束，音乐就会自动回升至 100%。

*   **优势**：您不必在尝试启动采访时使用鼠标降低推子。一切都是自动的。

## 5.3 音乐主导 (智能垫乐管理)

新手导演的一个经典错误是在节奏垫乐 (Bed) *之上*播放歌曲，造成声音混乱（鼓对鼓）。RLM 通过 **音乐主导 (Music Dominance)** 解决了这个问题。

*   **场景**：
    您有一个垫乐 (Show Asset) 在播音员的声音下循环播放。在某个时刻，您启动了一张唱片 (歌曲)。
*   **RLM 做什么**：
    软件不是停止垫乐（您可能需要在歌曲结束后准备好它），而是将其带到 **音量 0 (静音)**，但继续让它“幽灵般”运行。
*   **结果**：
    只听到歌曲。垫乐消失了。
*   **回归**：
    当歌曲结束（或您在歌曲上按停止）时，垫乐会自动淡入 (Fade In) 重新出现。

这允许您拥有连续的流“垫乐 -> 歌曲 -> 垫乐”，而无需第二次点击垫乐上的“播放”。

---

## 5.4 例外：“中断” (Stacchi)

如果您想在垫乐*之上*播放广播 Jingle，而又不让垫乐完全消失，会发生什么？
这时 **Behavior: Stacco** 设置就派上用场了（见第 4 章）。

*   如果资产列中的剪辑设置为“Normal”，它将停止其他垫乐。
*   如果设置为 **“Stacco”**，它将叠加在其他垫乐之上，稍微降低它们，但不会停止它们。这对于需要在曲目介绍或垫乐之上“驾驭”的台标 (Station ID)（“您正在收听 Runtime Radio...”）非常理想。
