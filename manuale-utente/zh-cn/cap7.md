# 第7章：项目管理与安全

配置节目需要时间：加载剪辑、调整音量、设置修剪。丢失这项工作将是灾难性的。
Runtime Live Machine 使用多级保存系统，以确保您的数据始终安全。

---

## 7.1 项目文件 (.lmp)

您节目的所有设置（剪辑位置、颜色、音量、MIDI 映射、淡入淡出设置）都保存在一个扩展名为 **.lmp** (Live Machine Project) 的文件中。

> **重要**：.lmp 文件是一个包含软件“指令”的文本文件 (JSON)。**它不包含物理音频文件**。它只存储文件在您计算机上的*路径*（例如 C:\Music\Intro.mp3）。

### 保存工作
在顶部的命令栏中，您有两个不同的选项：

1.  **💾 保存 (快速保存)**：
    *   点击软盘图标。
    *   立即覆盖当前打开的 .lmp 文件。
    *   这是您在工作时应定期执行的操作。
2.  **🖊️ 另存为**：
    *   点击带有笔的软盘图标。
    *   始终打开一个对话框以创建 **新文件**。
    *   使用它来创建节目的不同版本（例如 "Podcast_Ep1.lmp", "Podcast_Ep2.lmp"）。

### 关闭保护 (未保存的更改)
软件会持续监控您的操作。如果您进行了未保存的更改（加载了剪辑、更改了音量）并尝试关闭程序，RLM 将 **阻止关闭** 并显示警告：*“有未保存的更改”*。
您永远不会因为意外点击“X”而丢失工作。

---

## 7.2 自动备份 (安全网)

人们并不总是记得保存。因此，RLM 包含一个在后台运行的不可见 **自动备份 (Auto-Backup)** 系统。

*   **频率**：每 **5 分钟**，软件会自动保存当前状态的备份副本。
*   **备份去哪里了？**
    *   如果您正在处理已保存的项目（例如 MyShow.lmp），软件会在同一文件夹中创建一个名为 **MyShow.lmp.bak** 的“影子”文件。
*   **如何恢复它**：
    *   如果 PC 突然关闭或主文件损坏，请转到项目文件夹。
    *   查找 .bak 文件。
    *   通过删除 .bak 重命名它（或直接用 RLM 打开它）。您将恢复直到最后 5 分钟的工作。

---

## 7.3 收集并保存 (便携式导出)

对于那些在多台计算机上工作或想要存档节目的人来说，这是基本功能。
由于 .lmp 文件仅存储音频文件的*链接*，如果您只将该文件复制到另一台 PC（或 USB 驱动器），软件将无法再找到音乐（路径中断）。

要移动节目，您必须使用 **导出包 (Export Package)** 功能。

### 如何创建便携式包
1.  点击顶部栏中的 **📦 导出 (盒子)** 图标。
2.  系统将要求您选择一个空文件夹（例如，在您的 USB 驱动器上）。
3.  **复制过程**：
    *   软件分析整个项目。
    *   在目标位置创建一个名为 udio/ 的子文件夹。
    *   **物理复制**所有原始 MP3/WAV 文件到该文件夹中。
    *   创建一个新的 project.lmp 文件，其中所有链接都已重写为指向本地 udio/ 文件夹。

### 结果
您将得到一个包含所需一切的文件夹。您可以将 USB 驱动器插入任何安装了 Runtime Live Machine 的计算机，打开 project.lmp 文件，一切都将完美运行，无论驱动器号或原始路径如何。

> **推荐用途**：在每个节目准备结束时使用此功能创建一个“母版”，带到工作室或存档为完整的历史备份。
