# 第6章：硬件控制与路由

专业的导播软件不是孤立地存在于计算机中的。它必须与工作室调音台、耳机和导演的手指进行通信。
在本章中，我们将了解如何配置音频输出以及如何在不触摸鼠标的情况下控制软件。

---

## 6.1 音频配置 (路由)

默认情况下，RLM 输出到默认的 Windows 音频设备。但是，在工作室中（或使用像 *Rødecaster Pro* 这样的高级播客设置），您需要分离流。

### 选择输出
1.  点击顶部命令栏中的 **齿轮 (设置)** 图标。
2.  将打开 **通用设置 (General Settings)** 面板。
3.  在“音频输出设备 (Audio Output Device)”下拉菜单中，您将看到连接到 PC 的所有声卡的列表。
4.  选择所需的设备（例如 *Rødecaster Pro Stereo* 或 *Focusrite USB*）。

### 实时切换 (Live Switch)
更改是即时的。如果在您切换设备时正在播放音乐，音频将“跳”到新输出而不会中断。

> **Rødecaster/USB 混音器提示**：如果您的混音器有多个 USB 通道（例如 Main 和 Sounds/Chat），请将 RLM 设置为辅助通道（例如 "Sounds"），以便您可以使用物理混音器上的专用推子控制其音量，将其与 Windows 系统声音分开。

---

## 6.2 键盘 (热键)

计算机键盘是您拥有的最快的控制器。RLM 包含预设的全局命令和可自定义的键。

### 全局命令 (F 键)
功能键 (F1-F5) 映射为启动列。它们具有“智能”逻辑：它们会寻找第一个空闲的剪辑。
*   **F1**：启动第 1 列 (资产)。
*   **F2**：启动第 2 列 (音乐)。
*   **F3**：启动第 3 列 (人声)。
*   **F4**：启动第 4 列 (音效)。
*   **F5**：启动第 5 列 (预演)。
*   **ESC**：**紧急按钮 (PANIC BUTTON)**。立即停止所有内容 (Stop All)。

### 自定义键 (Custom Binds)
您想通过按空格键或字母“Q”来启动片头吗？
1.  右键点击剪辑 -> **Edit**。
2.  点击 **触发键绑定 (Trigger Keybind)** 字段。
3.  按键盘上所需的键。
4.  保存。
5.  卡片上会出现一个徽章（例如 **[Q]**）以提醒您该分配。

> **安全**：如果您正在输入文本（例如重命名剪辑），键盘命令将自动禁用，以避免在打字时启动音频。

## 6.3 MIDI 控制器 (物理力量)

这是典型的“Pro”功能。您可以连接音乐键盘、打击垫（如 *Novation Launchpad*）或推子控制器（如 *Korg nanoKONTROL*）并使用它们来驱动软件。

### 连接
1.  在启动 Runtime Live Machine **之前**，将您的 USB-MIDI 控制器连接到计算机。
2.  启动软件。MIDI 引擎将自动识别设备。

### MIDI 学习模式 (轻松映射)
您不需要知道复杂的代码。RLM 通过观察您的操作来学习。

1.  点击顶部栏中的 **MIDI** 图标 (DIN 接口)。
    *   图标变为 **青色 (开启)**。
    *   剪辑呈现虚线外观（“等待中”）。
2.  **映射剪辑**：
    *   用鼠标点击所需的剪辑。
    *   按下控制器上的物理按钮/打击垫。
    *   剪辑上会出现一个徽章（例如 **[M:60]**）。完成。
3.  **映射全局功能**：
    *   点击屏幕上的红色 **STOP ALL** 按钮 -> 按下控制器上的大按钮。
    *   点击屏幕上的 **MASTER VOL** 滑块 -> 移动控制器上的推子或旋钮。
4.  再次点击 **MIDI** 图标以退出学习模式。

### 支持的命令类型
*   **Note On/Off**：非常适合按钮和打击垫（剪辑启动、全部停止）。
*   **Control Change (CC)**：非常适合推子和旋转旋钮。使用它以模拟和平滑的方式控制总音量。

> **便携性**：剪辑 MIDI 映射保存在 .lmp 项目中。如果您将项目带到另一台具有相同控制器的 PC 上，一切都将立即工作。
