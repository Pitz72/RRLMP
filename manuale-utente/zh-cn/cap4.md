# 第 4 章 — 基础工作流：加载与播放

---

Runtime Live Machine Pro 的基本操作循环分三步：导入音频文件、在网格中整理、在直播中播放。本章会把每一步讲到足够精确，让你在压力下也能放心操作。

---

## 4.1 导入音频文件

RLMP 没有内部浏览器，也没有集中式媒体库。导入靠从操作系统文件管理器（Windows 的资源管理器、macOS 的 Finder、Linux 的 Nautilus 或同类工具）直接**拖放**。也可以从 FILE 菜单导入 **M3U** 播放列表，把它转换成一串片段。

### 基本动作

1. 打开存放音频文件的文件夹。
2. 选择一个或多个文件：`Ctrl+单击`选非连续的多个文件，`Shift+单击`选连续的一段。
3. 把选中的文件拖到网格某一列上方松手。音效则直接拖到 pad FX 上（第 7 章）。

每个文件都在目标列生成一张卡片。同时拖入多个文件时，卡片按文件在文件管理器中从上到下的顺序创建。

**插入指示器。** 拖动时一条发光蓝线会沿列滑动，指示卡片将插入的确切位置，方便你把新片段精确放到顶部、底部或中间任意一处。

### 支持的格式

集成的 FFmpeg 引擎兼容大量音频格式：

| 格式 | 扩展名 | 说明 |
|---|---|---|
| MP3 | `.mp3` | 全部 bitrate |
| WAV | `.wav` | 未压缩 PCM，任意位深度 |
| FLAC | `.flac` | Lossless，任意采样率 |
| AAC / M4A | `.aac`、`.m4a` | 含来自 iTunes/Apple Music 的文件 |
| OGG Vorbis | `.ogg` | |
| Opus | `.opus` | |
| WMA | `.wma` | Windows Media Audio |
| WebM / MP4 | `.webm`、`.mp4` | 这些容器中包含的音频轨 |

**关于性能。** `media://` 流式协议保证音频文件导入时不会被载入内存。一个 2 GB 的未压缩 WAV 文件和一个 5 MB 的 MP3 表现完全一样：加载瞬间完成，对系统内存的影响可以忽略。CPU 只在实际解码时——也就是播放期间——才被占用。

### 文件的路径

RLMP 记录的是文件在磁盘上的**绝对路径**，而不是文件本身的副本。移动、重命名或删除原始文件，对应卡片就会变红、无法播放。要在多台电脑上工作或创建便携式存档，用第 10 章描述的 **Export Package** 功能。

## 4.2 播放：启动与停止片段

### 启动片段

在卡片上**左键单击**就开始播放，反馈即时：卡片亮起为活动状态的绿色，计时器转为倒计时，页眉的 VU meter 反映输出信号。

若片段已分配键盘按键（见第 8 章），那个按键可以代替鼠标点击——手在别处忙、不想挪鼠标时很好用。

### 停止片段

**点击活动片段** — 片段进入**淡出**阶段，按其属性中配置的时间停止（见第 5 章）。

**`Esc` 键** — 瞬时停止所有活动片段，是紧急命令。RLMP 为活动窗口时就生效，哪怕光标停在文本框里。

**页眉中的 STOP ALL 按钮** — 效果与 `Esc` 完全相同，用鼠标操作。

### 按列的互斥逻辑

多数列里，RLMP 遵循**「一次一个片段」**的规则：本期歌曲列正播放*曲目 A*，点击同列的*曲目 B*，*曲目 A* 就会停止（带淡出）、*曲目 B* 启动。不需要先手动停掉正在播放的片段。

**pad FX 的效果**是主要例外：它们叠加在一切之上，包括其他效果，不会打断正在播放的内容——一段掌声可以在歌曲进行中响起而不打断歌曲。

设有 **Stacco** 行为的片段（属性中可配置，见第 5 章）也是叠加播放，不会停止列中的其他片段，无论它们在哪个位置。

## 4.3 整理播出单

### 重排片段

准备节目期间，甚至节目进行中，都可以随时重新排列片段顺序。

**列内拖动。** 点住一张卡片在同列内上下拖动，蓝色导引线指示插入位置，片段插入新位置时不会打断正在进行的播放。

**跨列移动。** 片段可以从一列拖到另一列，这时它会**继承目标列的规则**：一段预录人声被移到本期歌曲列后，就会像音乐曲目一样开始承受 ducking。

跨列移动是个分量不轻的操作，直播期间尤其要谨慎使用。

### 多选与删除

一次性从网格移除多个片段：

1. 对每个要选的片段做 `Ctrl+单击`（Windows/Linux）或 `Cmd+单击`（macOS），边框变蓝。
2. 按 `Canc` 或 `Delete`。选中数超过一个时软件会请求确认。

从网格删除只是把片段移出当前项目，不会删除磁盘上的音频文件。操作有误，`Ctrl+Z` 可以撤销。

> **操作建议。** 直播开始后，用多选加 `Canc` 清空 Pre-Show 列，是腾出界面视觉空间、切入操作模式最快的办法。

## 4.4 结构 cue：INTRO 与 OUTRO

每个片段都能在波形编辑器中配置两个**结构标记**（第 5 章）：

- **Intro 标记** — 曲目主旋律在乐器前奏之后真正进入的那一点，用来精确把握何时开始在 intro 上叠话。
- **Outro 标记** — 曲目结尾段落开始的那一点，标示准备转下一轨的时机。

播放接近这些点时，卡片上会出现视觉提示：

- **INTRO: −MM:SS** — 到 Intro 标记的倒计时。
- **OUTRO IN: −MM:SS** — 到 Outro 标记的倒计时，outro 开始后切换为 **🚨 OUTRO**。

这些提示只在配置了标记时出现。没有标记的片段，卡片只在曲目结束时显示标准倒计时。
