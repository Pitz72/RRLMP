# 第 4 章 — 基础工作流：加载与播放

---

Runtime Live Machine Pro 的基本操作循环分为三个阶段：导入音频文件、在网格中整理它们、在直播中播放它们。本章以在压力下也能安全工作所需的精度描述每一个阶段。

---

## 4.1 导入音频文件

RLMP 没有内部浏览器，也没有集中式的媒体库。导入通过从操作系统的文件管理器（Windows 上的资源管理器、macOS 上的 Finder、Linux 上的 Nautilus 或同类工具）直接**拖放**完成。此外，你也可以从 FILE 菜单导入一个 **M3U** 播放列表，将其转换为一串片段。

### 基本动作

1. 打开电脑上存放音频文件的文件夹。
2. 选择一个或多个文件。若要选择多个文件：`Ctrl+单击`用于非连续选择，`Shift+单击`用于连续选择。
3. 将选中的文件拖到网格的某一列上方并松手。对于音效，请直接把它们拖到 pad FX 上（第 7 章）。

每个文件都会在目标列中生成一张卡片。若你同时拖入多个文件，卡片会按文件在文件管理器中自上而下出现的顺序创建。

**插入指示器。** 拖动期间，一条发光的蓝线会沿列滑动，指示卡片将被插入的确切位置。你可以精确地把新片段插到顶部、底部或中间某个位置。

### 支持的格式

集成的 FFmpeg 引擎确保与大量音频格式的兼容：

| 格式 | 扩展名 | 说明 |
|---|---|---|
| MP3 | `.mp3` | 全部 bitrate |
| WAV | `.wav` | 未压缩 PCM，任意位深度 |
| FLAC | `.flac` | Lossless，任意采样率 |
| AAC / M4A | `.aac`、`.m4a` | 含来自 iTunes/Apple Music 的文件 |
| OGG Vorbis | `.ogg` | |
| Opus | `.opus` | |
| WMA | `.wma` | Windows Media Audio |
| WebM / MP4 | `.webm`、`.mp4` | 这些容器中包含的音频轨 |

**关于性能的一点说明。** `media://` 流式协议确保音频文件在导入时不会被载入内存 RAM。一个 2 GB 的未压缩 WAV 文件的表现与一个 5 MB 的 MP3 完全一致：加载是瞬时的，对系统内存的影响可以忽略。CPU 资源只在主动解码时——也就是播放期间——才被占用。

### 文件的路径

RLMP 记录的是文件在磁盘上的**绝对路径**，而非文件本身的副本。若你移动、重命名或删除原始文件，对应的卡片就会变红，不再可播放。若要在多台电脑上工作或创建便携式存档，请使用第 10 章描述的 **Export Package** 功能。

## 4.2 播放：启动与停止片段

### 启动片段

在卡片上**左键单击**即可开始播放。反馈是即时的：卡片亮起为活动状态的绿色，计时器转为倒计时，页眉中的 VU meter 反映输出信号。

若该片段已分配了键盘按键（见第 8 章），那个按键可作为单击的替代方式——当你正在界面的另一处操作、不想移动鼠标时很有用。

### 停止片段

**点击活动片段** — 该片段进入**淡出**阶段，并在其属性中配置的时间内停止（见第 5 章）。

**`Esc` 键** — 瞬时停止所有活动片段。这是紧急命令。当 RLMP 为活动窗口时生效，即使你正在文本框中输入。

**页眉中的 STOP ALL 按钮** — 与 `Esc` 完全相同，可用鼠标操作。

### 按列的互斥逻辑

在大多数列中，RLMP 应用**「一次一个片段」**的规则：若你正在 Canzoni（歌曲）列播放*曲目 A*，并点击同一列的*曲目 B*，则*曲目 A* 停止（带淡出），*曲目 B* 启动。无需在启动另一个片段之前手动停止正在进行的片段。

**pad FX 的效果**是主要的例外：它们叠加于一切之上，包括其他效果，且不会打断正在播放的内容。一段掌声可以在歌曲进行时启动，而不打断歌曲的播放。

设有 **Stacco** 行为的片段（可在属性中配置，见第 5 章）同样会叠加播放而不停止列中的其他片段，无论它们位于何处。

## 4.3 整理播出单

### 重排片段

在准备节目期间，甚至在节目进行中，你都可以随时重新组织片段的顺序。

**列内拖动。** 点击一张卡片，按住并在同一列内向上或向下拖动。蓝色导引线指示插入位置。片段会插入到新位置，而不打断正在进行的播放。

**跨列移动。** 你可以把片段从一列拖到另一列。这样做时，片段会**继承目标列的规则**：一段被移到 Canzoni 列的预录人声，将会像音乐曲目一样开始承受 ducking。

在列之间移动片段是一项强大而刻意的操作。请有意识地使用它，尤其是在直播期间。

### 多选与删除

若要一次性从网格中移除多个片段：

1. 对每个要选的片段执行 `Ctrl+单击`（Windows/Linux）或 `Cmd+单击`（macOS）。边框变蓝。
2. 按 `Canc` 或 `Delete`。若选中的片段数超过一个，软件会请求确认。

从网格删除只会将片段从当前项目中移除，不会从磁盘删除音频文件。若你操作有误，`Ctrl+Z` 可撤销。

> **操作建议。** 直播开始后，用多选加 `Canc` 清空 Pre-Show 列，是腾出界面视觉空间、切入操作模式的最快方式。

## 4.4 结构 cue：INTRO 与 OUTRO

每个片段都可以有两个在波形编辑器中配置的**结构标记**（第 5 章）：

- **Intro 标记** — 曲目主旋律在乐器前奏之后真正进入的那一点。用于精确掌握何时开始在 intro 上叠话。
- **Outro 标记** — 曲目结尾段落开始的那一点。标示准备转向下一轨的恰当时机。

当片段的播放接近这些点时，卡片上会出现视觉提示：

- **INTRO: −MM:SS** — 到 Intro 标记的倒计时。
- **OUTRO IN: −MM:SS** — 到 Outro 标记的倒计时，outro 开始时紧接着显示 **🚨 OUTRO**。

这些提示只有在配置了标记时才会显示。对于没有标记的片段，卡片仅在曲目结束时显示标准的倒计时。
