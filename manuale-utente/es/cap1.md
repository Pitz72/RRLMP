# CAPÍTULO 1: INTRODUCCIÓN Y CONFIGURACIÓN

Bienvenido a **Runtime Live Machine**.
Este capítulo le guiará a través de los primeros pasos: desde la comprensión de la filosofía del software hasta el primer inicio.

## 1.1 Qué es Runtime Live Machine (RLM)

**Runtime Live Machine** es una arquitectura de audio profesional diseñada para la dirección de **espectáculos en vivo individuales**, podcasts, eventos y radios web.

A diferencia del complejo software de automatización de radio 24/7 (que reproduce música en rotación durante días), RLM es una herramienta de **Rendimiento** (Performance). Está diseñado para ser "tocado" en tiempo real por un director o locutor.

### ¿Por qué elegir RLM?
*   **Filosofía "Single Show"**: Cada proyecto es un contenedor aislado que guarda todo lo necesario para ese episodio o evento específico.
*   **Motor de Audio Nativo**: Utiliza la tecnología *Direct Disk Streaming* para reproducir archivos de audio (WAV, MP3) instantáneamente sin cargarlos en la RAM, garantizando una estabilidad absoluta.
*   **Seguridad Total**: Incluye sistemas de Auto-Backup y advertencias de "Dead Air" para evitar el silencio en el aire.
*   **Control Físico**: Soporta nativamente controladores MIDI y teclados para una dirección táctil.

## 1.2 Instalación

### Requisitos del Sistema
*   **Windows**: Windows 10 o Windows 11 (64-bit).
*   **macOS**: macOS 11 (Big Sur) o posteriores (Soporte Apple Silicon & Intel).
*   **RAM**: Mínimo 4GB (8GB Recomendados).
*   **Espacio en Disco**: 200MB para la aplicación + espacio para sus archivos de audio.

### Instalación en Windows
1.  Descargue el archivo Runtime Live Machine Setup 1.0.0.exe desde el sitio oficial.
2.  Haga doble clic en el ejecutable.
3.  El instalador automático copiará los archivos y creará un acceso directo en el Escritorio.
4.  Al finalizar, la aplicación se iniciará automáticamente.

> **Nota de Seguridad**: Dado que el software se actualiza con frecuencia, Windows SmartScreen podría mostrar una advertencia "PC protegido por Windows". Haga clic en **"Más información"** y luego en **"Ejecutar de todas formas"**. El software es seguro y libre de malware.

### Instalación en macOS
1.  Descargue el archivo .dmg.
2.  Abra el archivo de imagen.
3.  Arrastre el icono de **Runtime Live Machine** a la carpeta **Aplicaciones**.
4.  En el primer inicio, es posible que deba autorizar la aplicación en *Preferencias del Sistema > Seguridad y Privacidad* si no proviene de la App Store.

## 1.3 La Pantalla de Bienvenida (Welcome Screen)

En el primer inicio, será recibido por la **Welcome Screen**. Este es su panel de inicio, diseñado para permitirle comenzar a trabajar en segundos.

### Elementos de la Pantalla
1.  **Estado de la Versión**: Debajo del logotipo, verá el número de la versión actual (ej. 1.0.0).
    *   ✅ **Verde**: Tiene la última versión disponible.
    *   ⬇️ **Amarillo/Naranja**: Hay una actualización disponible. El sistema verifica automáticamente los servidores al inicio.
2.  **Selector de Idioma**: En la parte superior derecha (o en el menú dedicado) encontrará banderas para cambiar el idioma de la interfaz.
    *   *Idiomas soportados*: Inglés (Predeterminado), Italiano, Francés, Alemán, Español, Portugués, Ruso, Chino.
    *   Su elección se guardará para futuros inicios.

### Acciones Disponibles
*   **Nuevo Proyecto (New Project)**: Crea una sesión vacía. Todas las columnas estarán limpias y listas para ser llenadas. Úselo para comenzar un nuevo episodio desde cero.
*   **Cargar Proyecto (Load Project)**: Abre un cuadro de diálogo para seleccionar un archivo .lmp (Live Machine Project) de su disco.
    *   *Consejo*: Los archivos .lmp contienen todos los ajustes de los clips, volúmenes, colores y asignaciones MIDI.
*   **Manual en Línea**: Abre este manual en su navegador predeterminado para una consulta rápida.

> **Primer Inicio**: Una vez que haga clic en "Nuevo Proyecto" o cargue un archivo, la interfaz se abrirá en pantalla completa para maximizar el espacio de trabajo. Está listo para salir al aire.
