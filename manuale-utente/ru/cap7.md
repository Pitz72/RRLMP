# ГЛАВА 7: УПРАВЛЕНИЕ ПРОЕКТАМИ И БЕЗОПАСНОСТЬ

Настройка шоу требует времени: загрузка клипов, регулировка громкости, установка обрезки. Потерять эту работу было бы катастрофой.
Runtime Live Machine использует многоуровневую систему сохранения, чтобы гарантировать, что ваши данные всегда в безопасности.

---

## 7.1 Файл проекта (.lmp)

Все настройки вашего шоу (позиции клипов, цвета, громкость, MIDI-назначения, настройки фейдов) сохраняются в одном файле с расширением **.lmp** (Live Machine Project).

> **Важно**: Файл .lmp — это текстовый файл (JSON), который содержит «инструкции» для программы. **Он НЕ содержит физические аудиофайлы**. Он запоминает только *путь*, где файлы находятся на вашем компьютере (например, C:\Music\Intro.mp3).

### Сохранение работы
На панели команд вверху у вас есть две разные опции:

1.  **💾 Сохранить (Быстрое сохранение)**:
    *   Нажмите значок Дискетой.
    *   Немедленно перезаписывает текущий открытый файл .lmp.
    *   Это действие нужно выполнять регулярно во время работы.
2.  **🖊️ Сохранить как (Save As)**:
    *   Нажмите значок Дискетой с Ручкой.
    *   Всегда открывает диалоговое окно для создания **нового файла**.
    *   Используйте это для создания разных версий шоу (например, "Podcast_Ep1.lmp", "Podcast_Ep2.lmp").

### Защита от закрытия (Несохраненные изменения)
Программа постоянно отслеживает ваши действия. Если вы сделали несохраненные изменения (загрузили клип, изменили громкость) и попытаетесь закрыть программу, RLM **заблокирует закрытие** и покажет предупреждение: *"Есть несохраненные изменения"*.
Вы никогда не потеряете работу из-за случайного нажатия на "X".

## 7.2 Авто-бэкап (Страховочная сеть)

Не всегда помнишь о сохранении. По этой причине RLM включает невидимую систему **Авто-бэкапа**, работающую в фоновом режиме.

*   **Частота**: Каждые **5 минут** программа автоматически сохраняет резервную копию текущего состояния.
*   **Куда попадает бэкап?**
    *   Если вы работаете над уже сохраненным проектом (например, MyShow.lmp), программа создает «теневой» файл в той же папке с именем **MyShow.lmp.bak**.
*   **Как его восстановить**:
    *   Если ПК внезапно выключится или основной файл будет поврежден, перейдите в папку проекта.
    *   Найдите файл .bak.
    *   Переименуйте его, убрав .bak (или откройте его напрямую с помощью RLM). Вы восстановите работу вплоть до последних 5 минут.

## 7.3 Collect & Save (Портативный экспорт)

Это фундаментальная функция для тех, кто работает на нескольких компьютерах или хочет архивировать шоу.
Поскольку файл .lmp хранит только *ссылки* на аудиофайлы, если вы скопируете только этот файл на другой ПК (или на флешку), программа больше не найдет музыку (пути будут разорваны).

Чтобы переместить шоу, вы должны использовать функцию **Export Package**.

### Как создать портативный пакет
1.  Нажмите значок **📦 Export (Коробка)** на верхней панели.
2.  Система попросит вас выбрать пустую папку (например, на вашей USB-флешке).
3.  **Процесс копирования**:
    *   Программа анализирует весь проект.
    *   Создает подпапку с именем udio/ в месте назначения.
    *   **Физически копирует** все оригинальные файлы MP3/WAV внутрь этой папки.
    *   Создает новый файл project.lmp, в котором все ссылки были переписаны, чтобы указывать на локальную папку udio/.

### Результат
Вы получите папку, содержащую все необходимое. Вы можете подключить USB-флешку к любому компьютеру с установленной Runtime Live Machine, открыть файл project.lmp, и все будет работать идеально, независимо от букв дисков или оригинальных путей.

> **Рекомендуемое использование**: Используйте эту функцию в конце подготовки каждого шоу, чтобы создать «Мастер» для переноса в студию или для архивации в качестве полной исторической резервной копии.
