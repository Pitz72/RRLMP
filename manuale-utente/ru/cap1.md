# ГЛАВА 1: ВВЕДЕНИЕ И УСТАНОВКА

Добро пожаловать в **Runtime Live Machine Pro (RRLMP)**.
Эта глава проведет вас через первые шаги: от понимания философии программного обеспечения до первого запуска.

## 1.1 Что такое Runtime Live Machine Pro (RRLMP)

**Runtime Live Machine Pro** — это профессиональная аудиоархитектура класса «Pro», разработанная для режиссуры **отдельных живых шоу**, подкастов, мероприятий и веб-радио.

В отличие от сложного программного обеспечения для круглосуточной автоматизации радио (которое воспроизводит музыку в ротации днями напролет), RRLMP — это инструмент для **выступлений** (Performance). Он создан для того, чтобы на нем «играли» в реальном времени режиссер или диктор, предлагая ювелирный контроль над каждым переходом.

### Почему стоит выбрать RRLMP?
*   **Философия «Single Show»**: Каждый проект — это изолированный контейнер, содержащий все необходимое для конкретного эпизода или мероприятия.
*   **Архитектура Main-Side-Heavy**: Использует прокси Node.js для тяжелого аудиодекодирования (FFmpeg), гарантируя плавность интерфейса (Renderer) и отсутствие сбоев даже при работе с большими WAV-файлами.
*   **Полная безопасность**: Включает системы автосохранения (Auto-Backup), проверку целостности файлов .lmp и визуальные предупреждения для меток Intro/Outro.
*   **Физическое управление**: Нативно поддерживает MIDI-контроллеры (с функцией MIDI Learn) и клавиатуры для тактильного и оперативного управления.

## 1.2 Установка

### Системные требования
*   **Windows**: Windows 10 или Windows 11 (64-бит).
*   **macOS**: macOS 11 (Big Sur) или новее (Нативная поддержка Apple Silicon и Intel).
*   **Linux**: Поддержка AppImage и пакетов .deb (Ubuntu/Debian/Mint).
*   **ОЗУ**: Минимум 4 ГБ (рекомендуется 8 ГБ).
*   **Дисковое пространство**: 200 МБ для приложения + место для ваших аудиофайлов.

### Установка на Windows
1.  Скачайте файл `Runtime Live Machine Pro Setup 1.0.0.exe` с официального сайта или из репозитория.
2.  Дважды щелкните по исполняемому файлу.
3.  Автоматический установщик скопирует файлы и создаст ярлык на рабочем столе.
4.  По завершении приложение запустится автоматически.

> **Примечание по безопасности**: Поскольку программное обеспечение часто обновляется, Windows SmartScreen может показать предупреждение «Система Windows защитила ваш компьютер». Нажмите **«Подробнее»**, а затем **«Выполнить в любом случае»**. Программное обеспечение безопасно, имеет цифровую подпись и не содержит вредоносных программ.

### Установка на macOS
1.  Скачайте файл `.dmg`.
2.  Откройте файл образа и перетащите значок **Runtime Live Machine Pro** в папку **Applications** (Программы).
3.  При первом запуске вам может потребоваться разрешить приложение в разделе *Системные настройки > Защита и безопасность*.

## 1.3 Экран приветствия (Welcome Screen)

При первом запуске вас встретит новый **Welcome Screen** с горизонтальным макетом. Это ваша стартовая панель, созданная для того, чтобы вы могли начать работу за считанные секунды.

### Элементы экрана
1.  **Новый логотип**: Логотип Pro (5 шкал VU-метра с треугольником воспроизведения) идентифицирует стабильную версию программного обеспечения.
2.  **Статус версии**: Под логотипом вы увидите номер текущей версии (например, `v1.0.0`).
    *   ✅ **Зеленый**: У вас установлена последняя версия.
    *   ⬇️ **Желтый/Оранжевый**: Доступно обновление.
3.  **Выбор языка**: В правом верхнем углу вы найдете флаги (8 поддерживаемых языков) для мгновенного изменения интерфейса.
    *   *Языки*: IT, EN, FR, DE, ES, PT, RU, ZH.
    *   Ваш выбор будет сохранен в профиле пользователя.

### Доступные действия
*   **Новый проект (New Project)**: Создает пустую сессию. Все 5 колонок (Assets, Music, Voice, SFX, PRE-SHOW) будут готовы к загрузке файлов.
*   **Загрузить проект (Load Project)**: Открывает существующий файл `.lmp`. RRLMP выполнит проверку целостности: если какие-либо аудиофайлы отсутствуют, они будут выделены красным цветом.
*   **Онлайн-руководство**: Открывает обновленную документацию в вашем браузере.

> **Первый запуск**: RRLMP предпочтительно запускается в полноэкранном режиме. После загрузки проекта вы заметите циановый бейдж **PRO** в заголовке, подтверждающий лицензию и стабильность аудиодвижка.
