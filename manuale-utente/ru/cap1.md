# ГЛАВА 1: ВВЕДЕНИЕ И УСТАНОВКА

Добро пожаловать в **Runtime Live Machine**.
Эта глава проведет вас через первые шаги: от понимания философии программного обеспечения до первого запуска.

## 1.1 Что такое Runtime Live Machine (RLM)

**Runtime Live Machine** — это профессиональная аудиоархитектура, разработанная для режиссуры **отдельных живых шоу**, подкастов, мероприятий и веб-радио.

В отличие от сложного программного обеспечения для круглосуточной автоматизации радио (которое воспроизводит музыку в ротации днями напролет), RLM — это инструмент для **выступлений** (Performance). Он создан для того, чтобы на нем «играли» в реальном времени режиссер или диктор.

### Почему стоит выбрать RLM?
*   **Философия «Single Show»**: Каждый проект — это изолированный контейнер, содержащий все необходимое для конкретного эпизода или мероприятия.
*   **Нативный аудиодвижок**: Использует технологию *Direct Disk Streaming* для мгновенного воспроизведения аудиофайлов (WAV, MP3) без загрузки их в оперативную память, гарантируя абсолютную стабильность.
*   **Полная безопасность**: Включает системы автосохранения (Auto-Backup) и предупреждения о «мертвом эфире» (Dead Air), чтобы избежать тишины в эфире.
*   **Физическое управление**: Нативно поддерживает MIDI-контроллеры и клавиатуры для тактильного управления.

## 1.2 Установка

### Системные требования
*   **Windows**: Windows 10 или Windows 11 (64-бит).
*   **macOS**: macOS 11 (Big Sur) или новее (Поддержка Apple Silicon и Intel).
*   **ОЗУ**: Минимум 4 ГБ (рекомендуется 8 ГБ).
*   **Дисковое пространство**: 200 МБ для приложения + место для ваших аудиофайлов.

### Установка на Windows
1.  Скачайте файл Runtime Live Machine Setup 1.0.0.exe с официального сайта.
2.  Дважды щелкните по исполняемому файлу.
3.  Автоматический установщик скопирует файлы и создаст ярлык на рабочем столе.
4.  По завершении приложение запустится автоматически.

> **Примечание по безопасности**: Поскольку программное обеспечение часто обновляется, Windows SmartScreen может показать предупреждение «Система Windows защитила ваш компьютер». Нажмите **«Подробнее»**, а затем **«Выполнить в любом случае»**. Программное обеспечение безопасно и не содержит вредоносных программ.

### Установка на macOS
1.  Скачайте файл .dmg.
2.  Откройте файл образа.
3.  Перетащите значок **Runtime Live Machine** в папку **Applications** (Программы).
4.  При первом запуске вам может потребоваться разрешить приложение в разделе *Системные настройки > Защита и безопасность*, если вы скачали его не из App Store.

## 1.3 Экран приветствия (Welcome Screen)

При первом запуске вас встретит **Welcome Screen**. Это ваша стартовая панель, созданная для того, чтобы вы могли начать работу за считанные секунды.

### Элементы экрана
1.  **Статус версии**: Под логотипом вы увидите номер текущей версии (например, 1.0.0).
    *   ✅ **Зеленый**: У вас установлена последняя версия.
    *   ⬇️ **Желтый/Оранжевый**: Доступно обновление. Система автоматически проверяет серверы при запуске.
2.  **Выбор языка**: В правом верхнем углу (или в специальном меню) вы найдете флаги для изменения языка интерфейса.
    *   *Поддерживаемые языки*: Английский (по умолчанию), Итальянский, Французский, Немецкий, Испанский, Португальский, Русский, Китайский.
    *   Ваш выбор будет сохранен для будущих запусков.

### Доступные действия
*   **Новый проект (New Project)**: Создает пустую сессию. Все колонки будут чистыми и готовыми к заполнению. Используйте это, чтобы начать новый эпизод с нуля.
*   **Загрузить проект (Load Project)**: Открывает диалоговое окно для выбора файла .lmp (Live Machine Project) с вашего диска.
    *   *Совет*: Файлы .lmp содержат все настройки клипов, громкости, цвета и назначения MIDI.
*   **Онлайн-руководство**: Открывает это руководство в браузере по умолчанию для быстрого ознакомления.

> **Первый запуск**: Как только вы нажмете «Новый проект» или загрузите файл, интерфейс откроется в полноэкранном режиме, чтобы максимизировать рабочее пространство. Вы готовы выйти в эфир.
