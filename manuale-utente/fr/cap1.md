# CHAPITRE 1 : INTRODUCTION ET CONFIGURATION

Bienvenue dans **Runtime Live Machine**.
Ce chapitre vous guidera à travers les premières étapes : de la compréhension de la philosophie du logiciel jusqu'au premier lancement.

## 1.1 Qu'est-ce que Runtime Live Machine (RLM)

**Runtime Live Machine** est une architecture audio professionnelle conçue pour la régie de **spectacles vivants individuels**, podcasts, événements et web radios.

Contrairement aux logiciels complexes d'automatisation radio H24 (qui diffusent de la musique en rotation pendant des jours), RLM est un outil de **Performance**. Il est pensé pour être "joué" en temps réel par un réalisateur ou un animateur.

### Pourquoi choisir RLM ?
*   **Philosophie "Single Show"** : Chaque projet est un conteneur isolé regroupant tout ce qui est nécessaire pour cet épisode ou événement spécifique.
*   **Moteur Audio Natif** : Utilise la technologie *Direct Disk Streaming* pour lire des fichiers audio (WAV, MP3) instantanément sans les charger dans la RAM, garantissant une stabilité absolue.
*   **Sécurité Totale** : Inclut des systèmes d'Auto-Backup et des avertissements "Dead Air" pour éviter le silence à l'antenne.
*   **Contrôle Physique** : Prend en charge nativement les contrôleurs MIDI et les claviers pour une régie tactile.

## 1.2 Installation

### Configuration Requise
*   **Windows** : Windows 10 ou Windows 11 (64-bit).
*   **macOS** : macOS 11 (Big Sur) ou ultérieur (Support Apple Silicon & Intel).
*   **RAM** : Minimum 4 Go (8 Go recommandés).
*   **Espace Disque** : 200 Mo pour l'application + espace pour vos fichiers audio.

### Installation sur Windows
1.  Téléchargez le fichier Runtime Live Machine Setup 1.0.0.exe depuis le site officiel.
2.  Double-cliquez sur l'exécutable.
3.  Le programme d'installation automatique copiera les fichiers et créera un raccourci sur le Bureau.
4.  Une fois terminé, l'application se lancera automatiquement.

> **Note de Sécurité** : Comme le logiciel est mis à jour fréquemment, Windows SmartScreen pourrait afficher un avertissement "PC protégé par Windows". Cliquez sur **"Informations complémentaires"** puis sur **"Exécuter quand même"**. Le logiciel est sûr et exempt de logiciels malveillants.

### Installation sur macOS
1.  Téléchargez le fichier .dmg.
2.  Ouvrez le fichier image.
3.  Glissez l'icône de **Runtime Live Machine** dans le dossier **Applications**.
4.  Au premier lancement, vous devrez peut-être autoriser l'application dans *Préférences Système > Sécurité et confidentialité* si vous ne venez pas de l'App Store.

## 1.3 L'Écran de Bienvenue (Welcome Screen)

Au premier lancement, vous serez accueilli par le **Welcome Screen**. C'est votre tableau de bord de départ, conçu pour vous permettre de commencer à travailler en quelques secondes.

### Éléments de l'Écran
1.  **État de la Version** : Sous le logo, vous verrez le numéro de la version actuelle (ex. 1.0.0).
    *   ✅ **Vert** : Vous avez la dernière version disponible.
    *   ⬇️ **Jaune/Orange** : Une mise à jour est disponible. Le système vérifie automatiquement les serveurs au démarrage.
2.  **Sélecteur de Langue** : En haut à droite (ou dans le menu dédié), vous trouverez les drapeaux pour changer la langue de l'interface.
    *   *Langues supportées* : Anglais (Par défaut), Italien, Français, Allemand, Espagnol, Portugais, Russe, Chinois.
    *   Votre choix sera mémorisé pour les futurs lancements.

### Actions Disponibles
*   **Nouveau Projet (New Project)** : Crée une session vide. Toutes les colonnes seront vierges et prêtes à être remplies. Utilisez ceci pour commencer un nouvel épisode à zéro.
*   **Charger un Projet (Load Project)** : Ouvre une boîte de dialogue pour sélectionner un fichier .lmp (Live Machine Project) sur votre disque.
    *   *Astuce* : Les fichiers .lmp contiennent tous les réglages des clips, les volumes, les couleurs et les mappages MIDI.
*   **Manuel en Ligne** : Ouvre ce manuel dans votre navigateur par défaut pour une consultation rapide.

> **Premier Lancement** : Une fois cliqué sur "Nouveau Projet" ou chargé un fichier, l'interface s'ouvrira en plein écran pour maximiser l'espace de travail. Vous êtes prêt à passer à l'antenne.
