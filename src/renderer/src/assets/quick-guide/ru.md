# Runtime Live Machine Pro — Краткое руководство

**Версия 1.15.10 · Русский**

Добро пожаловать в Runtime Live Machine Pro (RLMP) — программу для аудио плейаута радиостанций, прямых эфиров и живых мероприятий. Это руководство проведёт вас от установки до первого запуска воспроизведения за несколько минут. Полную документацию вы найдёте в Руководстве пользователя (скачивается из самой программы кнопкой «Руководство»).

---

## Что нового в этой версии

- **Экспорт проекта с аудио** — пункт меню ФАЙЛ (под *Сохранить как…*) собирает всё аудио в подпапку `audio/` и перенаправляет туда клипы: с этого момента архив становится эталоном проекта, и **вы можете безопасно удалить исходные файлы**. Раньше он назывался «Экспорт архива».
- **Очистить колонку** — значок корзины в заголовке каждой колонки удаляет все её клипы одним нажатием, с запросом подтверждения (отменяется через `Ctrl+Z`).
- **Значок Intro на карточках** — если у клипа задана точка Intro, голубой значок `I` с числом секунд остаётся всегда виден; значок BPM теперь ярко-жёлтый, повышенной заметности.
- **Улучшённые обновления внутри программы** — окно обновления стало больше и показывает реальные примечания к выпуску (changelog); при нажатии «Перезапустить и установить» приложение закрывается корректно, и установка запускается без сбоев.

## 1. Системные требования

| | Минимум | Рекомендуется |
|---|---|---|
| Windows | 10 64-бит | 11 64-бит |
| macOS | 11 Big Sur | 13 Ventura или новее |
| Linux | Ubuntu 20.04 / Debian 11 | Ubuntu 22.04 LTS |
| ОЗУ | 4 ГБ | 8 ГБ и более |
| Диск | 300 МБ | 1 ГБ + место для аудиофайлов |

Специализированная звуковая карта не требуется: RLMP работает с любым устройством, распознаваемым вашей системой, — от встроенного аудиовыхода до профессиональных USB-микшеров (Rødecaster Pro, Rødecaster Duo и др.). Программа нативно оптимизирована для Apple Silicon (M1/M2/M3).

## 2. Установка

**Windows**
1. Откройте загруженный файл `.exe`.
2. Если появится предупреждение *«Windows защитила ваш компьютер»*, нажмите **Подробнее** → **Выполнить в любом случае**. Это нормально для часто обновляемого программного обеспечения: вредоносного кода нет, исходный код доступен для публичной проверки.
3. Следуйте указаниям мастера установки. По завершении на Рабочем столе и в меню Пуск появится ярлык программы.

**macOS**
1. Откройте загруженный файл `.dmg`.
2. Перетащите значок Runtime Live Machine Pro в папку **Программы**.
3. При первом запуске, если macOS покажет предупреждение Gatekeeper, перейдите в **Настройки системы → Конфиденциальность и безопасность** и нажмите **Всё равно открыть** рядом с названием приложения.

**Linux**
- **AppImage** (портативная версия, без установки): сделайте файл исполняемым командой `chmod +x` и запустите его.
- **.deb** (Debian/Ubuntu/Mint): установите командой `sudo dpkg -i имя-файла.deb` или через графический менеджер пакетов.
- Если приложение не запускается, убедитесь, что установлен пакет `libasound2`, необходимый для поддержки ALSA.

## 3. Первый запуск

При открытии программы вы увидите **экран приветствия (Welcome Screen)**: здесь можно создать новый проект, загрузить существующий (`.lmp`), скачать Руководство пользователя или открыть это Краткое руководство. В правом верхнем углу можно выбрать язык интерфейса из восьми доступных.

После открытия проекта голубой значок **PRO** в заголовке подтверждает, что аудиодвижок активен. Нажмите `F11` (Windows/Linux) или `Ctrl+Cmd+F` (macOS), чтобы перейти в полноэкранный режим — рекомендуемый режим работы в прямом эфире.

## 4. Шесть колонок

RLMP организует всё содержимое в шесть фиксированных колонок, каждая со своим особым поведением:

| Колонка | Цвет | Поведение |
|---|---|---|
| **Show Assets** | Зелёный | Позывные, музыкальные подложки, институциональные джинглы |
| **Jingle** | Янтарный | Фирменные джинглы |
| **Promo** | Голубой | Промо и саморепрезентация |
| **Песни** | Красный | Музыкальный плейлист, подвержен Ducking, распознавание BPM |
| **Голоса** | Оранжевый | Наивысший приоритет: приглушает всё остальное |
| **Pre-Show** | Фиолетовый | Фоновая музыка перед началом прямого эфира, с опциональной ротацией |

У каждой колонки есть цветной индикатор в заголовке: нажмите на него, чтобы выбрать другой цвет из 30 доступных оттенков.

---

## 5. Пад FX и Automix

Помимо шести колонок, в заголовке доступны два быстрых инструмента:

- **FX** — открывает пад звуковых эффектов: запуск со свободным наложением, идеально для стингеров, аплодисментов, звуковых переходов.
- **MIX** — открывает вид Automix, деку, предназначенную для колонки Песни: совместимость по BPM, переходы с привязкой к битам и автоматический режим.

---

## 6. Загрузка и воспроизведение первого файла

1. Перетащите аудиофайл (MP3, WAV, AAC/M4A, OGG, FLAC) из Проводника / Finder прямо на колонку.
2. **Левый клик** по карточке запускает воспроизведение.
3. **Повторный клик** по активной карточке останавливает её с плавным затуханием (fade out), либо нажмите `Esc` для немедленной экстренной остановки всех клипов.

В большинстве колонок действует правило «один клип за раз»: запуск нового клипа автоматически останавливает воспроизводимый в этой же колонке. Исключение составляют пад FX и клипы в режиме Stacco — они свободно накладываются друг на друга.

---

## 7. Где получить помощь

- **Полное Руководство пользователя** — скачивается прямо из программы (кнопка «Руководство» на экране «Инфо»), подробно описывает каждую функцию (редактор волновой формы, Ducking, MIDI, запись, управление проектами, удалённое управление).
- **Официальный сайт и обновления** — цвет рядом с номером версии на экране приветствия показывает, доступно ли обновление (зелёный — версия актуальна, жёлтый/оранжевый — доступна новая версия).
