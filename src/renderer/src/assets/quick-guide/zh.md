# Runtime Live Machine Pro — 快速入门指南

**1.15.10 版 · 简体中文**

欢迎使用 Runtime Live Machine Pro（RLMP），一款专为广播电台、直播节目和现场活动打造的音频播出软件。本指南将带您在几分钟内完成从安装到首次播放的全过程。完整文档请参阅用户手册（可在软件内通过"手册"按钮下载）。

---

## 本版本新功能

- **导出项目含音频** — 文件菜单中的这一项（位于*另存为…*下方）会将所有音频归集到一个 `audio/` 子文件夹中，并把各片段重新指向该文件夹：自此该归档即成为项目的参照，**您可以安全地删除原始文件**。此功能原名"导出归档"。
- **清空列** — 每列标题栏中的垃圾桶图标可一次性移除该列的所有片段，操作前会要求确认（可用 `Ctrl+Z` 撤销）。
- **卡片上的 Intro 徽章** — 若某片段设置了 Intro 起播点，则会始终显示一个带秒数的青色 `I` 徽章；BPM 徽章现改为高辨识度的荧光黄色。
- **改进的应用内更新** — 更新窗口更大，并显示真实的发行说明（更新日志）；点击"重启并安装"后应用会干净地关闭，安装过程顺畅无阻。

## 1. 系统要求

| | 最低配置 | 推荐配置 |
|---|---|---|
| Windows | 10 64位 | 11 64位 |
| macOS | 11 Big Sur | 13 Ventura 或更高版本 |
| Linux | Ubuntu 20.04 / Debian 11 | Ubuntu 22.04 LTS |
| 内存 | 4 GB | 8 GB 或更高 |
| 磁盘空间 | 300 MB | 1 GB + 音频文件存储空间 |

无需专用声卡：RLMP 可与系统识别的任何音频设备配合使用，从内置输出到专业 USB 调音台（Rødecaster Pro、Rødecaster Duo 等）均可支持。软件针对 Apple Silicon（M1/M2/M3）进行了原生优化。

## 2. 安装

**Windows**
1. 打开下载的 `.exe` 文件。
2. 若出现"Windows 已保护你的电脑"提示，点击**更多信息** → **仍要运行**。这是频繁更新的软件的常见现象——软件不含任何恶意程序，源代码可公开查验。
3. 按照安装向导完成安装。安装完成后，桌面和开始菜单中会自动创建快捷方式。

**macOS**
1. 打开下载的 `.dmg` 文件。
2. 将 Runtime Live Machine Pro 图标拖入**应用程序**文件夹。
3. 首次启动时，如果 macOS 显示 Gatekeeper 安全提示，请前往**系统设置 → 隐私与安全性**，点击应用名称旁的**仍要打开**。

**Linux**
- **AppImage**（便携版，无需安装）：使用 `chmod +x` 赋予文件可执行权限后直接运行。
- **.deb**（Debian/Ubuntu/Mint）：使用 `sudo dpkg -i 文件名.deb` 安装，或通过图形化软件包管理器安装。
- 如果应用无法启动，请确认系统已安装 `libasound2` 软件包以支持 ALSA。

## 3. 首次启动

启动后您会看到**欢迎界面**，在这里可以新建项目、加载已有项目（`.lmp` 文件）、下载用户手册，或打开本快速入门指南。界面右上角可从八种可用语言中选择界面显示语言。

打开项目后，标题栏中的青色 **PRO** 徽章会亮起，表示音频引擎已启动。按下 `F11`（Windows/Linux）或 `Ctrl+Cmd+F`（macOS）可切换至全屏模式——这是现场导播工作时推荐使用的模式。

---

## 4. 六个栏目

RLMP 将所有内容组织为六个固定栏目，每个栏目都有专属的行为逻辑：

| 栏目 | 颜色 | 行为 |
|---|---|---|
| **Show Assets** | 绿色 | 台呼、音乐床、结构性串场音乐 |
| **Jingle** | 琥珀色 | 品牌识别短音乐 |
| **Promo** | 青色 | 宣传片与自我宣传内容 |
| **歌曲** | 红色 | 音乐播放列表，受 Ducking 影响，支持 BPM 检测 |
| **人声** | 橙色 | 最高优先级：压低其他所有音轨 |
| **Pre-Show** | 紫色 | 直播开始前的暖场音乐，可选循环轮播 |

每个栏目的标题栏都有一个彩色圆点：点击即可从 30 种可选颜色中选择新颜色。

---

## 5. 音效卡盘（Pad FX）与自动混音（Automix）

除六个栏目外，标题栏还提供两个便捷工具：

- **FX** — 打开音效卡盘：可自由叠加播放，非常适合插入音效、掌声、转场音效。
- **MIX** — 打开自动混音视图，专为歌曲栏目设计的调音台：支持 BPM 兼容性检测、节拍匹配转场以及自动播放模式。

---

## 6. 加载并播放第一个文件

1. 直接从文件资源管理器 / Finder 中将音频文件（MP3、WAV、AAC/M4A、OGG、FLAC）拖拽到某个栏目上。
2. **单击左键**点击卡片即可开始播放。
3. 再次**单击**正在播放的卡片，可淡出停止播放；或按下 `Esc` 键，立即紧急停止所有音轨的播放。

在大多数栏目中，规则是"同一时间只播放一个音轨"：启动新音轨会自动停止同一栏目中正在播放的音轨。音效卡盘（Pad FX）是例外，音效可以自由叠加播放。
