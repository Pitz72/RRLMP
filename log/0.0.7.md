# Log Dev 0.0.7 (Clip Settings Modal)
**Data**: 2026-01-04
**Autore**: Antigravity (Assistant)

## Nuove Funzionalità

### 1. Clip Settings Overlay
È ora possibile configurare ogni singola clip cliccando con il **Tasto Destro** sulla card.
Si apre un modale (Clip Settings) che permette di modificare:
-   **Nome**: Rinominare la traccia.
-   **Volume**: Slider da 0% a 150% (Gain).
-   **Loop**: Checkbox per attivare la riproduzione continua.
-   **Next Action**: Cosa fare alla fine ("Stop", "Play Next", "Loop").
-   **Ducking Role**: Ruolo nel mixer ("Source" = Priorità/Voce, "Target" = Sottofondo/Musica, "None").
-   **Custom Color**: Colore personalizzato per sovrascrivere quello della colonna.
-   **Elimina Clip**: Pulsante per rimuovere la traccia.

### 2. Aggiornamenti UI
-   **On Right Click**: Integrato menu contestuale per l'editing.
-   **Visual Feedback**: Le clip ora mostrano icone (Repeat) e badge (Priority) aggiornati in base alle impostazioni.
-   **Store Updates**: I metadati vengono salvati nello store di progetto (e persisteranno tra le sessioni quando implementeremo la persistenza su disco).
