## Problema Risolto: React Error #310 (Hooks Violation)
L'applicazione andava in crash o mostrava errori in console `Minified React error #310` quando venivano aggiunte clip.
**Causa**: L'hook `useAudioStore` veniva chiamato all'interno del metodo `.map()` in `MainGrid.tsx`. Quando il numero di clip cambiava, il numero di chiamate agli hook cambiava, violando le regole fondamentali di React.

## Soluzione Applicata
1.  **Refactoring**: Creata nuova componente `ClipCard.tsx`.
2.  **Incapsulamento**: Spostata tutta la logica di visualizzazione della singola clip e le relative chiamate agli hook (`useAudioStore`) dentro `ClipCard`.
3.  **Pulizia**: `MainGrid.tsx` ora renderizza semplicemente una lista di `<ClipCard />`, garantendo che l'ordine e il numero di hook per componente rimangano costanti.

## Risultato
Build eseguita con successo. L'interfaccia dovrebbe ora essere stabile anche aggiungendo dinamicamente nuove clip.
