## Problema Risolto: White Screen of Death (Drag & Drop)
Durante il test della build **v0.0.5**, il drag & drop di un file causava il render di una pagina bianca. 
**Causa**: Il browser (Electron) eseguiva il comportamento di default di navigazione verso il file droppato.

## Soluzione Applicata
1.  **Global Event Listener**: In `App.tsx`, aggiunti listener `dragover` e `drop` su `window` per chiamare `preventDefault()` e `stopPropagation()`. Questo intercetta l'evento prima che causi la navigazione.
2.  **Debug Mode**: Abilitati i DevTools automaticamente all'avvio nel processo Main (in produzione) per facilitare ulteriori diagnosi se necessario.

## Risultato
Eseguita nuova build. L'applicazione dovrebbe ora gestire correttamente il drop dei file sulla `MainGrid` senza navigare via.
