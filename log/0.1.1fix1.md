# v0.1.1fix1 - Ducking Priority Fix

**Data:** 2026-01-04
**Stato:** Bugfix

## Correzioni
*   **Conflitto Bed vs Musica**: I Bed (Assets) non attiveranno più il Ducking (volume basso) sulla Musica. La Musica deve dominare.
*   **Logica Raffinata**: Il Ducking automatico della musica scatta **SOLO** se la clip attiva:
    1.  Ha ruolo 'source' **E**
    2.  È nella colonna **VOCI / PREREGISTRAZIONI** oppure è uno **Stacco**.

## Defaults Aggiornati
*   Nuovi clip creati nella colonna **Assets** avranno di default `Ducking Role: None` (invece di Source).

## Verifica
*   Riproduci Musica -> Attiva Bed. La Musica resta alta, il Bed va a 0 (per la regola Music Dominance).
*   Riproduci Musica -> Attiva Voce. La Musica si abbassa (Ducking Vocale).
