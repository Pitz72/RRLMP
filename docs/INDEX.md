## 🚀 Guida Rapida per Sviluppatori

1. `npm install`
2. `npm run dev` (Nota: lo sviluppo richiede Node.js 18+ ed Electron 28).
3. Consulta l'**[Architettura](./ARCHITECTURE.md)** prima di modificare il motore audio.
