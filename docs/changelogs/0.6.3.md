# v0.6.3 - Stereo VU Meters 📊

**Data:** 31 Gennaio 2026
**Stato:** UI/Engine Feature

## 1. Stereo VU Meters
*   **Visualizzazione:** Due barre (Left/Right) inserite nella barra di controllo globale.
*   **Gradiente Colore:** Verde (Safe) -> Giallo (Warn) -> Rosso (Clip).
*   **Logica:** Monitoraggio *Post-Fader* (riflette il volume master).
*   **Engine:** Utilizza nodi analizzatori dedicati collegati in parallelo all'uscita master, separati per canale L/R.

## File Modificati
*   `engine/AudioContextManager.ts` (Channel Splitting & Analysers)
*   `hooks/useVUMeter.ts` (New Hook with RAF loop)
*   `components/ui/VUMeter.tsx` (New Component)
*   `components/ui/GlobalControls.tsx` (Integration)

## 2. New Project Button
*   **Funzionalità:** Permette di svuotare completamente il progetto corrente (reset di tutte le colonne).
*   **Sicurezza:** Richiede conferma se ci sono modifiche non salvate ("dirty state").
*   **UI:** Icona "File Plus" nel gruppo persistenza.

## 3. Visual Tags & Multi-Select
*   **Visual Tags:** Badge colorati sulla card per [STACCO], [LOOP], [NEXT].
*   **Selezione Multipla:**
    *   `Click`: Seleziona (e riproduce).
    *   `Ctrl+Click`: Aggiunge/Rimuove dalla selezione (senza riprodurre).
    *   **Stile:** Bordo blu evidente per le clip selezionate.
*   **Cancellazione Multipla:** Tasto `Canc` o `Backspace` per eliminare tutte le clip selezionate (con conferma).
