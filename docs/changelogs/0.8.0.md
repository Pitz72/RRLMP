# RRLM Director - v0.8.0 Release Log
**Data:** 02/02/2026
**Tipo:** Feature Release (MIDI)

## 🎹 MIDI Support (Beta)
È arrivato il supporto per controller MIDI esterni (USB).
- **MIDI Learn Mode:** Clicca il nuovo tasto "MIDI" nella barra superiore. Il programma entra in modalità apprendimento (bordo ciano tratteggiato).
- **Assegnazione Rapida:** Seleziona una clip e premi un tasto sul tuo controller MIDI per assegnarlo istantaneamente.
- **Visual Feedback:** Le clip mappate mostrano un badge (es. `M:60`) accanto al titolo.
- **Trigger:** In modalità normale, premendo il tasto MIDI assegnato la clip parte (o si ferma se è già in riproduzione).
- **Global Mapping:**
    - **Stop All:** Mappabile su qualsiasi tasto (Note/CC). Clicca "Stop All" in modalità Learn per assegnare.
    - **Master Volume:** Mappabile su Fader/Manopole (CC). Clicca l'area Volume in modalità Learn per assegnare.


## 🐧 Cross-Platform Build Support
Aggiornata la configurazione di build per supportare ufficialmente la compilazione su:
- **macOS:** Target `.dmg` (richiede compilazione su Mac).
- **Linux:** Target `.AppImage` e `.deb`.

## 🛠️ Internal
- Implementato `MidiManager` engine per la gestione di device USB-MIDI multipli.
