# Changelog Minor Release v0.3

# v0.3.1 - Streaming Protocol 2.0 (Architecture Fix)

**Data:** 2026-01-30
**Stato:** Critical Refactor

## Obiettivo
Risoluzione definitiva dei crash del Renderer (OOM - Out of Memory) e delle istantanee disconnessioni dei DevTools durante il Drag & Drop di file audio di grandi dimensioni (es. mixati da 1h).

## Modifiche Architetturali (Streaming Protocol 2.0)

### 1. Main Process (Backend)
Riscritto completamente l'handler del protocollo `media://` in `src/main/index.ts`.
*   **Range Requests (HTTP 206):** Supporto completo per le richieste parziali (scrubbing/seeking). Il backend ora serve il file a "chunk" (default 64KB) invece di caricarlo tutto in un buffer.
*   **Path Normalization:** Migliorata la gestione dei percorsi Windows/Unix e la decodifica URL.

### 2. Frontend & Memory Leak Fix
Eliminata completamente la dipendenza dagli oggetti `File` (Blob) nel renderer.
*   **Interface Update:** `StreamPlayer.load()` ora accetta **SOLO** stringhe (`path`). Passare un File object genererà un errore di compilazione.
*   **Protocol Switch:** `pathUtils.ts` ora forza il prefisso `media://` per tutti i percorsi locali, attivando automaticamente lo streaming via Main Process.
*   **Store Refactor:** `useAudioStore.ts` non accetta più oggetti File opzionali in `loadClip`, garantendo che nessun Blob venga mai creato in memoria RAM.

### 3. Effetti Riscontrati
*   **Zero RAM Impact:** Il caricamento di file da 500MB+ ora occupa ~0MB nel Renderer Heap (delegato allo stream C++ di Chromium).
*   **Seeking Fluido:** Spostarsi nella timeline non causa più glitch o attese, grazie al supporto `Range: bytes`.

# v0.3.0 - Persistence System

**Data:** 2026-01-30
**Stato:** Feature Update

## Nuove Funzionalità
1.  **Salvataggio Progetto**: Usa il pulsante "Save" (icona Floppy) per salvare l'intera configurazione corrente (clip, volumi, mapping) su un file `.lmp` (Live Machine Pro).
2.  **Caricamento Progetto**: Usa il pulsante "Load" (icona Cartella) per ripristinare una configurazione salvata.
3.  **Associazione File**: L'estensione `.lmp` è ora registrata nel sistema (richiede installazione).

## Modifiche Tecniche
*   Aggiunti handler IPC per dialoghi nativi di sistema.
*   Implementata serializzazione/deserializzazione dello stato del progetto.
*   Aggiornato `GlobalControls` con i nuovi pulsanti.

## Test Consigliati
1.  **Salva**: Configura una scaletta. Premi Salva. Verifica che venga creato un file.
2.  **Carica**: Chiudi e riapri l'app (o svuota tutto). Premi Carica. Seleziona il file. Verifica che le clip tornino al loro posto.
