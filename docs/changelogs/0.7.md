# RRLM Director - v0.7.3 Release Log
**Data:** 02/02/2026
**Tipo:** UX Fix & UI Polish

## 🔄 Closing Experience (UX)
Risolto il fastidioso comportamento alla chiusura dell'applicazione.
- **Start Maximized:** Il programma si avvia ora direttamente a schermo intero.
- **Smart Close:** Cliccando la "X" o premendo ALT+F4, se ci sono modifiche non salvate, appare finalmente un dialogo nativo chiaro: **"Salva"**, **"Non Salvare"**, **"Annulla"**.
- Niente più chiusure accidentali o "silent blocks".

## 💾 Gestione Salvataggi (UI)
La barra dei comandi globali è stata raffinata separando le azioni di salvataggio:
1.  **Salva (💾):** Sovrascrive direttamente il file corrente (se esiste). Molto più rapido.
2.  **Salva con nome (🖊️):** Apre sempre la finestra di dialogo per creare copie o versioni alternative.

## 🛠️ Internal
- Refactoring `src/main` IPC handlers per supportare `direct-save`.
- Ottimizzazione Handshake Chiusura (Renderer <-> Main).

# RRLM Director - v0.7.2 Release Log
**Data:** 02/02/2026
**Tipo:** Feature Update (Safety & Speed)

## 🛡️ Sicurezza Avanzata

### Auto-Backup
Lavora con serenità: il software ora esegue backup automatici del progetto attivo ogni **5 minuti**.
- **Progetti Esistenti:** Crea un file shadow `.bak` accanto al file di progetto originale.
- **Nuovi Progetti:** Salva copie temporanee nella cartella di sistema dell'app.
- **Non-Distruttivo:** L'auto-backup non sovrascrive MAI il tuo file `.lmp` principale mentre lavori.

### Avviso Chiusura
- Implementato un controllo prima della chiusura ("Unsaved Changes"). Se provi a chiudere l'app con modifiche non salvate, ti verrà chiesto di confermare.

## ✨ Editing Intelligente (Smart Trim)

### Magic Wand Tool 🪄
Nel pannello **Clip Settings**, ora trovi una bacchetta magica. Cliccando su "Auto-Detect Silence":
1.  Il software analizza la forma d'onda del file audio.
2.  Rileva automaticamente le parti silenziose all'inizio e alla fine (soglia -40dB).
3.  Imposta istantaneamente i valori di **Trim Start** e **Trim End**.
4.  Feedback immediato sui secondi rimossi.

Ideal per pulire rapidamente registrazioni vocali o brani con lunghi silenzi iniziali/finali.

# RRLM Director - v0.7.1 Release Log

In risposta al feedback degli utenti sulla funzionalità di esportazione introdotta nella v0.7.0, questo aggiornamento migliora significativamente l'esperienza utente durante il salvataggio di progetti di grandi dimensioni.

# RRLM Director - v0.7.0 Release Log
**Data:** 02/02/2026
**Tipo:** Aggiornamento Funzionale (Sicurezza & Portabilità)

## 🔔 Miglioramenti Chiave

### 1. 🚨 Dead Air Alert (Fine Playlist)
Per prevenire il silenzio accidentale ("Dead Air") durante una trasmissione live, l'applicazione ora monitora le clip attive:
- **Avviso Visivo:** Quando una clip è in riproduzione e soddisfa i seguenti criteri, l'intestazione della colonna lampeggerà in ambra con un avviso "DEAD AIR" / "END":
    - È l'**ultima clip** della colonna.
    - **Non è in loop**.
    - Mancano **meno di 20 secondi** alla fine.
Questo offre all'operatore tempo sufficiente per caricare la traccia successiva o preparare un intervento vocale.

### 2. 📦 Collect & Save (Export Progetto)
Rendi i tuoi progetti portabili! Il nuovo pulsante "Export / Pack Project" ti permette di fare il backup o spostare il tuo show:
- **Copia Completa Asset:** Copia tutti i file audio utilizzati nel progetto in una sottocartella dedicata `audio/`.
- **Relinking:** Genera un nuovo file `project.lmp` con percorsi relativi, assicurando che il progetto funzioni su qualsiasi computer (purché la cartella `audio` viaggi insieme al file `.lmp`).
- **Sicuro:** Non modifica il progetto attualmente aperto.

### 🐛 Correzioni & Rifiniture
- **Backend:** Aggiunto handler IPC `export-project` per le operazioni sul file system.
- **UI:** Aggiunto nuovo componente `ColumnHeader` per un feedback visivo migliore.
