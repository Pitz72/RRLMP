## ✨ Nuove Funzionalità

### 1. Auto-Silence Detection al Drop (Pre-Show)

Quando un file audio viene trascinato nella colonna **PRE-SHOW**, il sistema avvia automaticamente il rilevamento del silenzio in background (via FFmpeg, main process) e imposta `trimStart` / `trimEnd` senza nessuna azione manuale.

- Il workflow è **non bloccante**: il clip appare immediatamente sulla board, il trim viene applicato non appena FFmpeg completa l'analisi (~1-2 secondi).
- Se il file non ha silenzio rilevabile, nessun trim viene applicato (silent fail corretto).
- Utilizza la stessa infrastruttura IPC (`detect-silence`) del pulsante Auto-Trim manuale.

**File modificati**: `MainGrid.tsx`

---

### 2. Sistema di Transizioni Configurabili

Le clip della colonna Pre-Show (e qualsiasi clip con `nextAction: 'play_next'`) ora supportano tre modalità di transizione tra brani.

#### Tipi di Transizione

| Tipo | Comportamento |
|---|---|
| **Gapless** | Taglio netto coda-testa. La nuova clip parte esattamente quando la precedente finisce. Default. |
| **Segue** | La clip precedente sfuma verso il silenzio mentre la nuova parte immediatamente a volume pieno. |
| **Crossfade** | Sovrapposizione bilanciata: la vecchia clip sfuma E la nuova sale contemporaneamente. |

#### Default Globale — Impostazioni Generali
Aggiunta sezione **"Pre-Show Transition"** in `General Settings`:
- Pulsanti per selezionare il tipo di transizione default (Gapless / Segue / Crossfade)
- Slider per la **durata della transizione** (500ms – 8000ms), visibile solo quando il tipo è Segue o Crossfade

#### Override Per-Clip — Clip Settings
In `Clip Settings → General Settings`, nuovo selettore **"Transizione Sequencer"**:
- `Default`: usa il valore delle Impostazioni Generali
- `Gapless` / `Segue` / `Crossfade`: forza il tipo per questa specifica clip

#### Implementazione Engine
- **`transitioningClips`** (module-level `Set`): traccia le clip in fase di fade-out per una transizione. La conflict resolution di `playClip` salta queste clip invece di stopparle bruscamente.
- **`pendingCrossfadeFadeIn`** (one-shot number): passa la durata del fade-in alla clip entrante nel caso crossfade.
- **`applyTransitionAndPlayNext()`**: helper interno che determina il tipo effettivo (override clip || default globale) e orchestra il timing.

**File modificati**: `useAudioStore.ts`, `useSettingsStore.ts`, `GeneralSettingsModal.tsx`, `ClipSettingsModal.tsx`

# Changelog v0.13.1 (2026-04-06)

## Bugfix Critici

- **Protocollo `media://`**: Corretto bug nel parsing degli URL che causava il fallimento del caricamento di file con caratteri speciali (come apostrofi o spazi) su sistemi Windows.
- **Silence Detection**: Ripristinata la funzionalità di scansione automatica del silenzio, che era interrotta a causa del malfunzionamento del protocollo media.
- **Update Checker**: Migliorata la gestione degli errori nel controllo aggiornamenti. Il sistema ora ignora correttamente le risposte non-JSON (come le pagine di errore HTML 404), evitando crash silenziosi o errori di sintassi nei log.

## Miglioramenti

- **Robustezza URI**: Implementata una gestione centralizzata e coerente degli URL tramite `toFileUrl` in tutti i moduli del Renderer.
- **Main Process Protocol**: Il gestore del protocollo `media:` è ora più tollerante verso le diverse varianti di slash passate da Chromium.

# Changelog v0.13.0 (2026-04-06)

## Nuove Funzionalità: Continuous-Play & Automation

- **Sistema di Transizioni Intelligenti**: Implementato supporto per `Crossfade`, `Segue` e `Gapless` nella colonna Pre-Show.
- **Configurazione Globale e Locale**: Aggiunta impostazione di transizione predefinita nelle "General Settings" e possibilità di override per singola clip nelle "Clip Settings".
- **Auto-Silence Detection (Pre-Show)**: I file caricati nella colonna Pre-Show vengono ora analizzati automaticamente per rimuovere i silenzi all'inizio e alla fine, garantendo passaggi fluidi tra i brani.
- **Sequencer Avanzato**: Ottimizzata la logica di avvio della clip successiva basata sul tipo di transizione selezionato.

## Miglioramenti Tecnici

- **Refactoring TypeScript**: Eliminazione di numerosi `any` e `@ts-ignore` in tutto il progetto (`MidiManager`, `AudioProcessor`, `index.ts`, `useAudioStore`).
- **Ottimizzazione Mix Bus**: I cambi di output device ora avvengono alla radice dell'Audio Graph (AudioContext sinkId), garantendo stabilità totale durante il passaggio tra schede audio.
- **Waveform Peak Amplification**: Amplificata la visualizzazione dei picchi per una migliore leggibilità dei file con volume basso.
- **LMP Integrity Check**: Diagnostica automatica all'apertura del progetto per segnalare file audio mancanti.
