# Changelog v0.9.18 (2026-04-05)

## 🎯 Obiettivi della Release
Questa release risolve criticità medie riguardanti la stabilità della funzione "Auto-Detect Silence" e la chiarezza dell'interfaccia utente in caso di impostazioni di riproduzione contrastanti.

## 🛠️ Fix & Miglioramenti

### 🟡 UX & Algoritmi (M5, M6)
- **Robustezza Smart Trim (M5)**: Implementata una protezione nella funzione `detectSilence` (Clip Settings) per gestire i casi degeneri. Se un file audio è interamente silenzioso, corrotto o ha un volume troppo basso per superare la soglia di analisi, il sistema ora interrompe l'operazione con un avviso invece di applicare un trim che eliminerebbe l'intera clip.
- **Risoluzione Conflitti Playback (M6)**: Aggiunto un avviso visivo dinamico nel `ClipSettingsModal`. Quando un utente attiva sia il "Looping" che l'azione "Autoplay Next", il sistema mostra ora un banner informativo che chiarisce la priorità del loop, evitando ambiguità sul comportamento del sequencer.

## 📈 Stato del Progetto
Con questa release, la copertura delle criticità "Medie" sale al **100%**, completando tutti i task prioritari identificati per la fase di rifinitura.
