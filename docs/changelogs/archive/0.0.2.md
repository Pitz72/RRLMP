# Log 0.0.2 - Implementazione Project Store

**Data**: 2026-01-03
**Autore**: Antigravity (Assistant)

## Riepilogo
Implementato il "Cervello" dell'applicazione (Zustand Project Store) definendo le 5 colonne strutturali (Swimlanes) richieste per l'architettura radiofonica.

## Dettagli Implementazione

### 1. Project Store (`useProjectStore.ts`)
Ho aggiornato lo store includendo:
- **Struttura a 5 Colonne Statiche ma Dinamiche**:
  - `SHOW ASSETS` (Verde, Assets, Locked)
  - `MUSIC PLAYLIST` (Rosso, Music, Unlocked)
  - `VOICE / GUESTS` (Arancione, Voice, Unlocked)
  - `SFX / CARTWALL` (Grigio, SFX, Unlocked)
  - `PRE-SHOW` (Viola, Preshow, Unlocked)
- **Logica `addClip`**:
  - Normalizzazione automatica del nome file (rimozione estensione).
  - Acquisizione path nativo (Electron File Object).
  - Impostazione ID univoco (UUID).
  - **Auto-Configurazione Ducking**:
    - Le clip in *VOICE* e *ASSETS* agiscono come **Source** (abbassano il volume).
    - Le clip in *MUSIC* e *PRE-SHOW* agiscono come **Target** (vengono abbassate).
- **Gestione Stato**: Aggiunte funzioni per rimuovere (`removeClip`) e aggiornare (`updateClip`) le clip.
