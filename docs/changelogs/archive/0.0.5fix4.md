## Problema Risolto: Renderer Crash su Drag & Drop
L'applicazione andava in crash (schermata grigia) subito dopo il drop di un file audio.
**Causa**:
1.  URL del file malformati (`fetch` su Windows richiede protocollo `file://` esplicito e path normalizzati).
2.  Assenza di gestione errori nel caricamento dei file (un errore di fetch non catturato crashava il renderer process).

## Soluzione Applicata
1.  **Nuova Utility**: `pathUtils.ts` con funzione `toFileUrl` per convertire path assoluti in URL file validi (gestione slash e encoding).
2.  **BufferPlayer**: Aggiunto `try/catch` attorno al caricamento e uso di `toFileUrl`.
3.  **StreamPlayer**: Uso di `toFileUrl` per `src` e listener `onerror`.
4.  **AudioStore**: Aggiunto blocco `try/catch` nell'azione `loadClip` per prevenire crash se il probing del file fallisce.

## Risultato
Il sistema di caricamento file è ora robusto. Errori di lettura file vengono loggati in console ma non bloccano l'interfaccia.
