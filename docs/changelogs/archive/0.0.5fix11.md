## Problema: Crash Memoria Renderer
Il ritorno del crash "DevTools disconnected" con la fix10 indica che, ora che il file viene trovato correttamente, il tentativo di caricarlo tutto in RAM (`BufferPlayer` -> `arrayBuffer()`) esaurisce la memoria del processo Renderer per file grandi (WAV).

## Fix: Streaming Totale
1.  **Forzato `StreamPlayer`**: Ho disabilitato temporaneamente `BufferPlayer` in `useAudioStore`. Ora **tutti** i file (Musica, Jingles, Voci) usano `StreamPlayer`. Questo usa 0 memoria RAM dedicata, affidandosi allo streaming su disco/rete.
2.  **Streaming Nativo (Main)**: Ho aggiornato il protocollo `media://` per usare `fs.createReadStream` e `Readable.toWeb` invece di `net.fetch`.
    - Questo collega direttamente il FileSystem all'Audio Element.
    - Performance massime, utilizzo memoria minimo.
