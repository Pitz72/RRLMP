# v0.2.1 - Pre-Show Logic

**Data:** 2026-01-30
**Stato:** Feature Update

## Nuove Funzionalità
1.  **Pre-Show Auto-Play**: Le clip trascinate nella colonna "PRE-SHOW" ora hanno automaticamente l'impostazione "Play Next" e dissolvenza a 0 (Gapless). Quando ne finisce una, parte la successiva.
2.  **Show Start Integration**: Quando viene lanciata una clip dalla colonna "SHOW ASSETS" (es. Sigla, Bed), qualsiasi musica del Pre-Show viene fermata istantaneamente.

## Test Consigliati
1.  **Playlist Continua**: Carica 2-3 canzoni nel Pre-Show. Lancia la prima. La seconda deve partire subito dopo la fine della prima.
2.  **Start Show**: Lancia una canzone Pre-Show. Poi clicca su un asset (es. Sigla). Il Pre-Show deve interrompersi subito.
