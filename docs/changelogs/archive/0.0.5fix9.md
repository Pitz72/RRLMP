**Data**: 2026-01-03

## Problema: Crash JS `webUtils object is undefined`
L'errore `Cannot read properties of undefined (reading 'getPathForFile')` ha rivelato che l'oggetto `webUtils` non è correttamente importato o esposto nel preload script in questa specifica configurazione di build/versione di Electron.

## Fix: Fallback Robusto
Ho riscritto `src/preload/index.ts` per essere difensivo:
1.  Importa `webUtils` via ES Module (`import {...} from 'electron'`).
2.  Controlla a runtime se `webUtils` e `webUtils.getPathForFile` esistono.
3.  Se esistono, li usa (Standard Moderno).
4.  Se NON esistono (errore attuale), fa fallback sulla proprietà legacy `file.path` che nel contesto Preload dovrebbe essere ancora accessibile, garantendo la continuità funzionale.

Questo assicura che il Renderer riceva sempre un path valido (o stringa vuota) senza lanciare eccezioni che bloccano l'esecuzione.
