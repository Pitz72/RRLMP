# RRLM Director - v0.7.1 Release Log
**Data:** 02/02/2026
**Tipo:** Patch Aggiornamento (UX Improvements)

## 📦 Miglioramenti Collect & Save

In risposta al feedback degli utenti sulla funzionalità di esportazione introdotta nella v0.7.0, questo aggiornamento migliora significativamente l'esperienza utente durante il salvataggio di progetti di grandi dimensioni.

### ✨ Feedback Visivo di Esportazione
- **Barra di Progresso in Tempo Reale:** Ora viene mostrata una finestra modale durante l'esportazione che indica:
    - La percentuale di completamento.
    - Il file attualmente in fase di copia.
    - Il conteggio dei file processati rispetto al totale.
- **Prevenzione Freeze:** L'interfaccia non "congela" più durante la copia, fornendo rassicurazione all'operatore che il processo è attivo e funzionante.

### 🔧 Dettagli Tecnici
- Implementato sistema di eventi IPC `export-progress` dal processo principale al renderer.
- Aggiunto componente `ExportProgressModal`.
