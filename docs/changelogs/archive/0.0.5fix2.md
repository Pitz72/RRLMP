**Data**: 2026-01-03

## Problema Risolto: Preload Script Missing
L'avvio dell'applicazione segnalava errore `Unable to load preload script`, mandando in crash il processo di inizializzazione sicura di Electron.
**Causa**: Mancava la directory `src/preload` e il relativo processo di compilazione TypeScript nel chain di build.

## Soluzione Applicata
1.  **Creato `src/preload/index.ts`**: Script di preload base (espone `window.electron` se non isolated, o usa `contextBridge`).
2.  **Creato `tsconfig.preload.json`**: Configurazione dedicata per compilare `src/preload` in `out/preload`.
3.  **Aggiornato `package.json`**: 
    - Aggiunto script `build:preload`.
    - Modificato script `build` per includere `npm run build:preload`.

## Risultato
Eseguita nuova build. L'applicazione dovrebbe avviarsi senza errori di modulo mancante.
I DevTools sono ancora abilitati come da fix precedente.
