# v0.1.1 - Music Dominance & Background Swap

**Data:** 2026-01-04
**Stato:** Feature Release

## Nuove Funzionalità

### 1. Dominio Musicale (Music Dominance)
Le **Canzoni dell'Episodio** (nuovo nome per Music Playlist) ora "comandano" sugli **Assets** (Show Assets).
*   **Start Canzone**: Se ci sono Asset in riproduzione (es. Bed), questi scendono a Volume 0 in 500ms ma continuano a girare.
*   **Swap Silenzioso**: Se una Canzone sta suonando e lanci un *nuovo* Asset, questo parte direttamente a Volume 0 (pronto per riemergere).
*   **Restore**: Quando la Canzone finisce, gli Asset (nuovi o vecchi che siano) risalgono dolcemente (2000ms) al loro volume originale.

### 2. UI Update
*   Rinominata colonna "MUSIC PLAYLIST" in "CANZONI DELL'EPISODIO".

## File Modificati
*   `useProjectStore.ts`: Update titolo colonna.

## Note di Test

3. Mentre la Canzone va, lancia un *altro* Bed. Deve partire muto.
4. Ferma la Canzone. Il nuovo Bed deve fare Fade In (2 sec).
