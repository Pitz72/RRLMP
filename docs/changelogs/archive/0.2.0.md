# v0.2.0 - UI/UX Improvements

**Data:** 2026-01-30
**Stato:** Feature Update

## Nuove Funzionalità
1.  **Global Stop**: Aggiunto un pulsante rosso "STOP ALL" nella barra superiore. Ferma istantaneamente tutte le tracce audio attive.
2.  **Master Volume**: Aggiunto uno slider per il controllo del volume generale dell'applicazione. Persiste finché l'app è aperta.
3.  **Compact Mode**: Ridotta l'altezza delle card delle clip per visualizzare più elementi nello stesso spazio. Ottimizzato per schermi con molte tracce.

## Modifiche Tecniche
*   Aggiornato `AudioContextManager` per esporre il controllo master gain.
*   Nuovo componente `GlobalControls`.
*   Restyling CSS per `ClipCard` (padding ridotto p-3 -> p-2).

## Test Consigliati
*   Avviare più clip e premere "STOP ALL".
*   Regolare il Master Volume e verificare che influenzi tutte le uscite (Musica, Voci, ecc.).
*   Verificare la leggibilità delle clip con il nuovo layout compatto.
