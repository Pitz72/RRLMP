# Changelog v0.9.6
*Date: 2026-02-03*

## 🔴 Critical Fixes
- **Windows Flag Compatibility**: Completely rewrote `FlagIcon.tsx` to use inline SVGs. Resolved issue where Windows rendered text letters instead of emoji flags. Now displays graphical flags for EN, IT, FR, DE, ES, PT, RU, CN.
- **Dynamic Versioning**: Implemented `__APP_VERSION__` injection via Vite.
  - Removed hardcoded version strings in `WelcomeScreen`, `AboutModal`, `GlobalControls`.
  - Application now reads version directly from `package.json` (v0.9.6).

## 🛠 Maintenance
- **Build Link**: `builds/0.9.6/`
- **Configuration**: Updated `vite.config.ts` and `env.d.ts` for type-safe version injection.
