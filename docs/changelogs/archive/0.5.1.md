# v0.5.1 - Critical Hotfix 🚑

**Data:** 2026-01-30
**Stato:** Hotfix

## Problema Risolto
*   **Fix Riproduzione Audio:** Risolto un bug critico introdotto nella v0.4.0 che causava il blocco del player (`Buffer Hang`) se il caricamento del file via protocollo `media://` falliva o impiegava troppo tempo.
*   **Miglioramenti Debug:** Aggiunti log dettagliati nel pannello "Log Stream" per intercettare eventuali errori di decodifica o file non trovati (`Failed to play clip`).

## Dettagli Tecnici
*   **StreamPlayer:** Rimossa la soppressione degli errori in `onerror` per il protocollo `media://`. Ora gli errori vengono correttamente gestiti e non lasciano il sistema in uno stato "Pending" infinito.
*   **AudioStore:** Migliorata la cattura delle eccezioni nella funzione `playClip`.

*   `src/renderer/src/store/useAudioStore.ts`
