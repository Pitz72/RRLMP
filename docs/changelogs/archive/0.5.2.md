# v0.5.2 - WAV Fix 📝

**Data:** 2026-01-30
**Stato:** Hotfix

## Problema Risolto
*   **Supporto File WAV:** Risolto un errore (`DEMUXER_ERROR_COULD_NOT_OPEN`) che impediva la riproduzione di file `.wav` (e altri formati non-MP3).
    *   **Causa:** Il server interno dichiarava erroneamente tutti i file come `audio/mpeg`.
    *   **Soluzione:** Il sistema ora identifica correttamente il formato (`audio/wav`, `audio/ogg`, `audio/mp4`, `audio/flac`) permettendo al motore audio di decodificarli correttamente.

*   `src/main/index.ts` (Dynamic Content-Type logic)
*   `package.json` (v0.5.2)
