# v0.5.0 - Global Hotkeys 🎹

**Data:** 2026-01-30
**Stato:** Feature Release

## Obiettivo
Implementare il controllo da tastiera per le funzioni di regia (Play/Stop), aumentando la velocità operativa e l'accessibilità.

## Nuove Funzionalità

### Tasti Funzione (F1 - F5)
Ogni tasto attiva la riproduzione intelligente per una colonna specifica:
*   **F1:** Colonna 1 (Assets)
*   **F2:** Colonna 2 (Music)
*   **F3:** Colonna 3 (Voice)
*   **F4:** Colonna 4 (SFX)
*   **F5:** Colonna 5 (Pre-Show)

**Smart Logic:**
*   Il comando cerca la **prima clip libera** (che non è in riproduzione).
*   Se nessuna clip sta suonando, lancia la prima della lista.
*   Se una clip sta suonando, lancia la successiva disponibile.

### Panic Button (ESC)
*   **ESC:** Ferma immediatamente tutte le riproduzioni attive (`STOP ALL`).

### Safety Guards
I comandi vengono automaticamente ignorati se:
*   L'utente sta scrivendo in un campo di testo (es. rinominando una clip).
*   Un modale (es. Impostazioni Clip) è aperto.

## Dettagli Tecnici
*   **Store:** Aggiornato `useAudioStore` con l'azione `playColumn(index)`.
*   **Listeners:** Implementato `Global Key Listener` in `MainGrid.tsx`.
*   **Guards:** Controllo su `document.activeElement` e stato `editingClip`.
