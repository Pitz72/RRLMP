## Problema: Crash Persistente su Drag & Drop
Schermata grigia e disconnessione DevTools al drop dei file, nonostante i fix precedenti.

## Ipotesi e Fix
1.  **Revert `webSecurity: false`**: La disabilitazione della sicurezza web globale, combinata con `contextIsolation`, potrebbe causare instabilità nel motore di rendering di Electron (noto problema su alcune versioni). Ho riabilitato la sicurezza (`true`).
2.  **Rimozione Accesso `file.path`**: L'accesso alla proprietà non standard `.path` su un oggetto `File` nel processo Renderer (con isolation attiva) potrebbe innescare un errore di sicurezza a livello C++ (V8 proxy trap). Ho rimosso l'accesso: ora memorizziamo una stringa vuota. L'audio viene riprodotto esclusivamente tramite l'oggetto `File` in memoria (Blob).

## Note
L'app ora usa standard web puri (`URL.createObjectURL` e `ArrayBuffer`).
Se questo fix risolve il crash, confermeremo che il problema era l'accesso insicuro alle proprietà native o la configurazione `webPreferences`.
