# v0.5.3 - Fix Decoding Percorsi 🛣️

**Data:** 2026-01-30
**Stato:** Hotfix Urgente

## Problema Risolto
*   **Audio con Spazi/Caratteri Speciali:** Risolto definitivamente l'errore `DEMUXER_ERROR_COULD_NOT_OPEN` che si verificava quando il percorso del file conteneva spazi (es. `JINGLE UMBERTO.wav`) o caratteri speciali.
    *   **Causa:** Il protocollo `media://` non decodificava correttamente l'URL ricevuto dal player (es. `%20` non veniva convertito in spazio), rendendo il percorso illeggibile per il sistema operativo.
    *   **Soluzione:** Implementata una logica rigorosa di *Decoding URI* e sanitizzazione del percorso nel Main Process, garantendo la compatibilità con percorsi Windows complessi.

## File Modificati
*   `src/main/index.ts` (URI Decoding Fix)
*   `package.json` (v0.5.3)
