## Problema: `net::ERR_UNEXPECTED` su Drive Esterno (J:)
Il test sul fix precedente ha mostrato un errore di fetch. Analizzando il log `media://J:/...` sembra che l'URL formato con doppio slash (`//`) causi un'interpretazione errata dell'authority (host) da parte del parser URL di Electron, trattando `J:` come host invece che parte del path, o causando problemi nel `decodeURIComponent` se non gestito perfettamente.

## Fix: Standardizzazione URI
1.  **Triple Slash**: Modificato `pathUtils` per generare `media:///${path}`. Questo è lo standard URI per "local file no host".
2.  **Robust Parsing**: Aggiornato il Main Process per usare una regex `^media:\/*` che rimuove qualsiasi variante di slash iniziale, garantendo che ciò che resta sia il path pulito.
3.  **Error Handling**: Aggiunto blocco `try/catch` nel protocol handler per intercettare malformazioni e loggare l'errore specifico invece di crashare silenziosamente o dare errori generici.
