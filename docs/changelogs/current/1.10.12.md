# v1.10.12 — Pad FX "acceso" nel colore scelto (effetto luminoso)

**Data:** 2026-07-02

Versione **patch** — rifinitura su riscontro dev: il velo di colore di v1.10.10 (~18%) era troppo timido; il pad colorato deve **accendersi**, come effetto luminoso, dello stesso colore vivace scelto dalla modale.

## Cosa cambia (`FxPadOverlay.tsx`)

Cella con `customColor` assegnato:
- riempimento più pieno (~28% del colore),
- **bordo a colore pieno**,
- **glow esterno** (`0 0 18px`) + **bagliore interno** (inset) nello stesso colore — lo stesso linguaggio luminoso dello stato "in onda",
- testo bianco per la leggibilità sul fondo acceso.

Le priorità di stato restano invariate: **in onda = verde** (il colore personalizzato non lo sovrascrive), file mancante = rosso, MIDI Learn = cyan.
