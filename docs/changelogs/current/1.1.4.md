## Novità

### Export Recording Modal — Formato + Qualità + Salvataggio

Sostituisce i vecchi pulsanti inline WAV/WEBM con un dialog di esportazione completo.

**Formati supportati:**
| Formato | Tipo | Qualità |
|---------|------|---------|
| WAV | Lossless | 16 / 24 / 32-bit (selezionabile) |
| FLAC | Lossless compresso | 16 / 24-bit (selezionabile) |
| MP3 | Lossy | 128 / 192 / 256 / 320 kbps |
| OGG | Lossy / Vorbis | 128 / 192 / 256 / 320 kbps |
| WEBM | Opus nativo | 128 / 192 / 256 / 320 kbps |

**Flusso:**
1. Registrazione terminata → appare pulsante "ESPORTA"
2. Click "ESPORTA" → si apre `RecordingExportModal`
3. Utente sceglie formato, bitrate o bit depth
4. Click "Scegli Destinazione…" → dialog di sistema per percorso/nome
5. Conversione via FFmpeg (main-side) → toast di successo con path
6. UI torna a stato IDLE (tasto REC)

**Note tecniche:**
- FFmpeg (`AudioProcessor.convertAudio`) esteso per supportare MP3 (`libmp3lame`), FLAC (`flac`), OGG (`libvorbis`) oltre a WAV e WEBM già presenti.
- FLAC 24-bit usa `sample_fmt s32` (FFmpeg richiede s32 per FLAC 24-bit).
- `useRecordingStore.exportRecording()` accetta ora `{ format, bitrate?, sampleDepth? }`.
- `RecordingButton.tsx` usa stati booleani espliciti invece di `if (tempPath)` → più leggibile e prevedibile.
