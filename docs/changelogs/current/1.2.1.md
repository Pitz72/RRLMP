## Fix

### Fix critico: protocollo `media://` su macOS e Linux
- Il percorso file perdeva lo slash iniziale (`/Users/simone/...` → `Users/simone/...`) su macOS/Linux, rendendo l'audio engine non funzionale su queste piattaforme.
- Aggiunto ripristino slash iniziale per piattaforme non-Windows nel handler `media://` in `src/main/index.ts`.

### Fix: colori clip dinamici
- Le clip aggiunte a una colonna con `customColor` impostato ereditavano correttamente il colore visivo in real-time (`effectiveColor`), ma al momento della creazione veniva assegnato `col.color` (default), non `col.customColor`.
- Corretto `addClip`, `addClipAtIndex` e `addClipFromPath` in `useProjectStore.ts`: ora usano `col.customColor || col.color`.

## Infrastruttura

### macOS Build
- Aggiunto `build/entitlements.mac.plist` con permessi: audio-input, file read-write, network client, JIT.
- `package.json`: sezione `mac` aggiornata con `entitlementsInherit` e `NSMicrophoneUsageDescription`.

### Preload / IPC
- Aggiunto `openExternal(url)` → IPC `open-external` (per il download dell'aggiornamento).
- Aggiunto `getPlatform()` → `process.platform` (per selezionare l'asset corretto nell'updater).
