## 1 — Preview Transizione: Pulsante Stop + Protezione hasPlayed

### Problema

Il sistema di anteprima transizione (Test→) avviava la clip in riproduzione ma non aveva un pulsante di stop. L'unico modo per fermarla era usare il pulsante globale "STOP ALL". Inoltre, le clip riprodotte durante il preview venivano marcate come `hasPlayed: true`, diventando grigie come se fossero state trasmesse per davvero — creando confusione visiva nel PRE-SHOW.

### Fix — Stop button

In `ClipSettingsModal.tsx`, il pulsante "Test→" è ora affiancato da un pulsante "Stop" (rosso, icona `StopCircle`) che appare **solo quando il preview è attivo** per quella specifica clip. Il pulsante Test→ viene disabilitato durante il preview attivo.

```tsx
{isPreviewingThisClip && (
    <button onClick={() => stopPreviewTransition(clip.id)} ...>
        <StopCircle size={13} /> Stop
    </button>
)}
```

### Fix — hasPlayed

In `useAudioStore.ts` è stato aggiunto un set `previewingClipIds: string[]` nel store state. Quando `previewTransition()` viene chiamata, il `clip.id` viene aggiunto a questo set **prima** di avviare la riproduzione. In `stopClip()`, la logica `hasPlayed` viene saltata se l'ID è in `previewingClipIds`. Quando la transizione fa partire la clip successiva (`applyTransitionAndPlayNext`), anche questa viene aggiunta al set se la clip corrente era in preview.

```typescript
// In stopClip():
const isPreviewClip = state.previewingClipIds.includes(clipId);
if (active.clip.type === 'preshow' && !isPreviewClip) {
    // ... setHasPlayed
}
```

Aggiunta anche l'azione `stopPreviewTransition(clipId)` che ferma tutti i clip attivi in modalità preview e svuota `previewingClipIds`.

**File modificati**: `src/renderer/src/store/useAudioStore.ts`, `src/renderer/src/components/modals/ClipSettingsModal.tsx`

## 2 — GeneralSettingsModal: Refactor a Schede (Tab)

### Cambiamento

La modal delle impostazioni generali è stata riorganizzata da un layout a due colonne affiancate a un sistema a **3 tab**:

| Tab | Contenuto |
|-----|-----------|
| 🎚️ **Output & Mix** | Dispositivo audio di uscita, Ducking (intensità + velocità), Transizioni default (crossfade/segue/gapless + durate) |
| ⛓️ **Master Chain** | HPF, Compressore broadcast, Limiter brickwall (invariati) |
| 🌐 **Lingua** | Selezione lingua dell'interfaccia (grid 2 colonne con bandiere) |

La tab attiva è evidenziata da un bordo inferiore verde (`border-emerald-500`) con sfondo `bg-zinc-800`. La larghezza massima passa da `max-w-4xl` a `max-w-2xl` (più compatta, si adatta meglio a risoluzioni broadcast tipiche).

Il cambio lingua è **immediato** (i18n.changeLanguage) con indicatore ✓ sulla lingua attiva.

**File modificati**: `src/renderer/src/components/modals/GeneralSettingsModal.tsx`, `src/renderer/src/locales/en.json`, `src/renderer/src/locales/it.json`

## 3 — WelcomeScreen: Redesign Orizzontale con Bandiere

### Cambiamento

La schermata di benvenuto è stata completamente ridisegnata in un layout a **due pannelli orizzontali** (720px totali):

**Pannello sinistro** (azioni principali):
- Logo + Titolo (invariati)
- **Slogan**: "On Air. In Control." / "On Air. Al Tuo Controllo."
- **Descrizione breve**: testo di presentazione dell'app in 2 righe
- Badge versione + stato aggiornamento
- Pulsanti Nuovo Progetto / Carica Progetto / Manuale (invariati)
- Footer credits

**Pannello destro** (220px, sfondo più scuro):
- Titolo sezione "Interface Language" / "Lingua dell'Interfaccia"
- Lista verticale di 8 lingue, ognuna con **bandiera SVG** + nome
- La lingua attiva ha bordo `cyan-500` e sfondo `cyan-500/10` con check ✓
- Nessun dropdown/globe: selezione diretta e sempre visibile

Rimosso: `Globe` (lucide-react), dropdown `isLangOpen` — non più necessari.

**File modificati**: `src/renderer/src/components/modals/WelcomeScreen.tsx`, `src/renderer/src/locales/en.json`, `src/renderer/src/locales/it.json`
