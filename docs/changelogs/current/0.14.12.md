## Feature 1 — Import Playlist M3U → colonna PRE-SHOW

Nuovo pulsante `ListMusic` nella toolbar (dopo "Carica Progetto") che importa una playlist `.m3u` / `.m3u8` direttamente nella colonna PRE-SHOW.

### Flusso

1. Click sul pulsante "Importa Playlist M3U → PRE-SHOW"
2. Dialog di selezione file filtrato per `.m3u` / `.m3u8`
3. Il main process legge e parsa il file:
   - Salta righe `#EXTM3U`, `#EXTINF:...` e righe vuote
   - Risolve path relativi rispetto alla cartella dell'M3U
   - Filtra path non esistenti su disco e file non audio
4. Le tracce valide vengono aggiunte sequenzialmente alla colonna PRE-SHOW con:
   - `nextAction: 'play_next'` (default PRE-SHOW)
   - Auto-silence detection IPC in background su ogni traccia
5. Toast di conferma: `"M3U importata — N tracce aggiunte a PRE-SHOW"`

### Compatibilità

| Sistema | Supporto |
|---------|----------|
| M3U semplice (path assoluti) | ✅ |
| M3U con path relativi | ✅ (risolti rispetto alla cartella del file) |
| M3U8 (UTF-8) | ✅ |
| Extended M3U (`#EXTINF`) | ✅ (le direttive vengono saltate, solo i path vengono letti) |
| File audio supportati | mp3, wav, ogg, m4a, aac, flac, opus, wma |

## Feature 2 — Clip PRE-SHOW già suonate: effetto visivo

Le clip della colonna PRE-SHOW che sono già state riprodotte appaiono visivamente attenuate così l'operatore può capire a colpo d'occhio da dove ripartire.

### Comportamento

- Quando una clip PRE-SHOW termina la riproduzione (`stopClip`), viene impostato `hasPlayed: true` (persistito nel `.lmp`)
- La ClipCard mostra la clip con `opacity-50` e sfondo `zinc-950` — distinta chiaramente dalle clip non ancora suonate
- Lo stato si azzera aprendo un nuovo progetto (reset completo)
- Il campo è persistito nel `.lmp` — riaprendo il progetto lo stato è conservato

### Campo aggiunto

```ts
// AudioClip
hasPlayed?: boolean; // persistito nel .lmp
```

| File | Modifica |
|------|----------|
| `src/renderer/src/types/index.ts` | Aggiunto `hasPlayed?: boolean` ad `AudioClip` |
| `src/renderer/src/store/useAudioStore.ts` | In `stopClip()`: se clip PRE-SHOW → `updateClip(..., { hasPlayed: true })` |
| `src/renderer/src/components/layout/ClipCard.tsx` | Classe condizionale `opacity-50 bg-zinc-950` se `clip.hasPlayed && clip.type === 'preshow'` |
