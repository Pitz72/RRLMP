# Changelog v0.14.3 (2026-04-07)

## 🚨 Feature Release: Emergency Stop Globale (Escape → stopAll)

Questa release implementa il punto **§4.2** della VISION.md ("Hotkey Globale Emergency Stop", priorità 🔴 CRITICO). La pressione del tasto `Escape` ferma immediatamente **tutte le clip in riproduzione** tramite `globalShortcut` Electron, garantendo il funzionamento anche quando il focus è su un elemento interno all'app (modali, input, canvas).

---

## 🔍 Funzionamento

### Flusso Emergency Stop

1. L'utente preme `Escape` (in qualsiasi momento, app in primo piano)
2. Il main process intercetta la scorciatoia via `globalShortcut`
3. Viene inviato l'evento IPC `emergency-stop` a tutte le finestre aperte
4. Il preload bridge trasporta l'evento al renderer via `onEmergencyStop`
5. Il renderer chiama `useAudioStore.getState().stopAll()`
6. Tutti i player vengono fermati e il mix viene azzerato istantaneamente

### Caratteristiche

- **Globale a livello di app**: funziona anche con un input testuale, modale o canvas in focus
- **Basato su OS-level globalShortcut**: la registrazione avviene nel main process Electron
- **Cleanup corretto**: `globalShortcut.unregisterAll()` su `app.on('will-quit')` — nessun leak
- **Idempotente**: se non ci sono clip attive, la chiamata a `stopAll()` è no-op

### Nota su Comportamento Globale OS

`globalShortcut` in Electron intercetta il tasto a livello di OS quando la finestra è in primo piano. Per design, `Escape` viene riservato come Emergency Stop esclusivo dell'app. In modalità broadcast professionale questo è il comportamento corretto: il tasto di emergenza deve essere affidabile e immediato.

## 🏗️ Architettura IPC

### Main Process (registrazione scorciatoia)
```typescript
globalShortcut.register('Escape', () => {
    BrowserWindow.getAllWindows().forEach(w => {
        if (!w.isDestroyed()) w.webContents.send('emergency-stop');
    });
});

app.on('will-quit', () => {
    globalShortcut.unregisterAll();
});
```

### Preload Bridge
```typescript
onEmergencyStop: (callback: () => void) => {
    const subscription = () => callback();
    ipcRenderer.on('emergency-stop', subscription);
    return () => ipcRenderer.removeListener('emergency-stop', subscription);
},
```

### Renderer (App.tsx)
```typescript
const unsubscribeEmergencyStop = window.electron.onEmergencyStop(() => {
    useAudioStore.getState().stopAll();
});
// cleanup nel return del useEffect
```

## ⚠️ Limitazioni Note

- `globalShortcut` funziona solo quando la finestra RRLMP è **in primo piano** (focused). Per garantire Emergency Stop anche con l'app in background servirebbe un approccio OS-nativo diverso (non necessario per uso broadcast standard)
- Non viene mostrato alcun feedback visivo (toast/flash) al momento del Emergency Stop — il feedback è implicito: tutte le clip smettono di muoversi
