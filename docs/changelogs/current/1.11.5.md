# v1.11.5 — Auto-Updater reale + repo pubblica RRLMP-Releases

**Data:** 2026-07-02

## Contesto

Richiesta esplicita dell'utente: sostituire il vecchio sistema di notifica
aggiornamenti (fetch verso `ecosystem.mruntimeradio.com/updates/rlmp/versions.json`,
mai installazione automatica) con `electron-updater` reale, pubblicando le
build compilate su una repo pubblica dedicata (`Ecosystem-Runtime/RRLMP-Releases`)
mentre la repo di sviluppo resta privata. Popup di aggiornamento all'avvio e
dal pulsante manuale in Info, mai durante la diretta.

## Repo pubblica

Creata `Ecosystem-Runtime/RRLMP-Releases` — README con descrizione,
changelog sintetico e banner (`branding/banner-rlmp-pro-v1.11.4.jpg`,
renderizzato dall'SVG via Electron headless). Nessun codice sorgente, solo
release binarie.

## Auto-Updater (`src/main/updateManager.ts`)

Due percorsi in base alla piattaforma:
- **Windows e Linux AppImage**: `electron-updater` nativo (`autoDownload:false`
  — il download parte solo al click "Scarica" nel popup, mai in automatico).
  check → download → `quitAndInstall`.
- **macOS non firmato e Linux .deb**: nessun certificato Apple Developer,
  `electron-updater` non può installare in modo affidabile → fallback via
  GitHub Releases API (`api.github.com/repos/Ecosystem-Runtime/RRLMP-Releases/releases/latest`,
  confronto semver) + apertura browser sull'asset corretto.

Nuovi IPC (`check-for-updates`, `download-update`, `quit-and-install`) ed
evento broadcast `updater:status` verso il renderer.

## Gating "mai durante la diretta"

Stato centralizzato in `App.tsx`: un solo listener sull'evento IPC, un solo
`UpdateModal` renderizzato. Il popup automatico (avvio app) si accoda se
`onAirStartTime !== null` (stesso flag di `OnAirTimer`) e si apre da solo
appena la diretta finisce (`stopAll`). Il pulsante "Controlla aggiornamenti
ora" in Info (nuovo, in `AboutModal`) ignora il gating per definizione —
azione esplicita dell'utente, sempre immediata.

## CI (`build.yml`)

Aggiunta build Windows (mancava, solo Linux+macOS prima). Nuovo job
`release` (opzionale, input `publish_release`) che pubblica gli installer
dei 3 OS su RRLMP-Releases via `softprops/action-gh-release@v2` (secret
`RELEASE_TOKEN`, riusa il PAT dell'org già in uso per il push su origin).

## Rimozioni

`src/renderer/src/utils/updateChecker.ts` eliminato. `UpdateModal.tsx`
riscritto per consumare `UpdaterStatusPayload` invece del vecchio
`UpdateInfo` fetchato lato renderer.

## Pulizia storage

Cancellati su `Ecosystem-Runtime/RRLMP`: 2 Artifact Actions obsoleti da
~600MB (build v1.6.0) + 2 Artifact APK Android (progetto abbandonato in
v1.11.3) + 12 Actions cache (Gradle/npm residue dello stesso progetto).
