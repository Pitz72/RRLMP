## ✨ Nuove Funzionalità

### 1. Auto-Silence Detection al Drop (Pre-Show)

Quando un file audio viene trascinato nella colonna **PRE-SHOW**, il sistema avvia automaticamente il rilevamento del silenzio in background (via FFmpeg, main process) e imposta `trimStart` / `trimEnd` senza nessuna azione manuale.

- Il workflow è **non bloccante**: il clip appare immediatamente sulla board, il trim viene applicato non appena FFmpeg completa l'analisi (~1-2 secondi).
- Se il file non ha silenzio rilevabile, nessun trim viene applicato (silent fail corretto).
- Utilizza la stessa infrastruttura IPC (`detect-silence`) del pulsante Auto-Trim manuale.

**File modificati**: `MainGrid.tsx`

### 2. Sistema di Transizioni Configurabili

Le clip della colonna Pre-Show (e qualsiasi clip con `nextAction: 'play_next'`) ora supportano tre modalità di transizione tra brani.

#### Tipi di Transizione

| Tipo | Comportamento |
|---|---|
| **Gapless** | Taglio netto coda-testa. La nuova clip parte esattamente quando la precedente finisce. Default. |
| **Segue** | La clip precedente sfuma verso il silenzio mentre la nuova parte immediatamente a volume pieno. |
| **Crossfade** | Sovrapposizione bilanciata: la vecchia clip sfuma E la nuova sale contemporaneamente. |

#### Default Globale — Impostazioni Generali
Aggiunta sezione **"Pre-Show Transition"** in `General Settings`:
- Pulsanti per selezionare il tipo di transizione default (Gapless / Segue / Crossfade)
- Slider per la **durata della transizione** (500ms – 8000ms), visibile solo quando il tipo è Segue o Crossfade

#### Override Per-Clip — Clip Settings
In `Clip Settings → General Settings`, nuovo selettore **"Transizione Sequencer"**:
- `Default`: usa il valore delle Impostazioni Generali
- `Gapless` / `Segue` / `Crossfade`: forza il tipo per questa specifica clip

#### Implementazione Engine
- **`transitioningClips`** (module-level `Set`): traccia le clip in fase di fade-out per una transizione. La conflict resolution di `playClip` salta queste clip invece di stopparle bruscamente.
- **`pendingCrossfadeFadeIn`** (one-shot number): passa la durata del fade-in alla clip entrante nel caso crossfade.
- **`applyTransitionAndPlayNext()`**: helper interno che determina il tipo effettivo (override clip || default globale) e orchestra il timing.

**File modificati**: `useAudioStore.ts`, `useSettingsStore.ts`, `GeneralSettingsModal.tsx`, `ClipSettingsModal.tsx`
