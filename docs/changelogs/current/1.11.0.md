# v1.11.0 — AUTOMIX (MINOR di consolidamento)

**Data:** 2026-07-02

Versione **MINOR**: consolida la feature Automix, completa (Fasi A-D del piano `docs/automix/PROMPT-SESSIONE-AUTOMIX.md`) e **approvata dall'utente in dev**. Nessun cambio di codice rispetto alla v1.10.27: solo il numero, come da piano ("MINOR a feature completa").

## La feature, in sintesi (v1.10.16 → v1.10.27)

- **Rilevamento** (Fase A): BPM + fase della griglia dei beat (`beatOffsetSec`) + confidence, persistiti nel `.lmp` (gate versionato `bpmCheckedV2`), validati strumentalmente su musica reale (docs/automix/VALIDAZIONE-A3.md).
- **Motore** (Fase B): `engine/automixEngine.ts` puro — `planTransition` decide beat-match (rate octave-aware, cap ±8%, aggancio sul beat, crossfade 8 battute) o crossfade classico, con motivi espliciti; 26 test.
- **Sezione Automix** (Fase C): vista full-screen in linguaggio Spectrum (toggle MIX in topbar), scaletta = colonna Music con semafori di compatibilità, deck IN ONDA/PROSSIMO, pulsantone TRANSIZIONE, START, opzione "Auto a fine brano" (default OFF, attiva solo a vista aperta).
- **Sicurezza** (Fase D): confidence <0.5 o dati mancanti → crossfade classico annunciato; partenza entrante fallita → uscente intatto; ESC resta Emergency Stop; telemetria completa nel Debug Overlay.
- **Orchestrazione**: `useAudioStore.automixTransition` riusa il motore esistente (playClip/fadeTo/fadingClipIds); `StreamPlayer.setPlaybackRate` con pitch preservato; correzione di fase post-avvio; rientro del rate a 1.0 (0.1%/s). Fix critico v1.10.26 (ordine marker vs conflict resolution).
- Inclusi nella corsa: modali Impostazioni a 2 colonne (v1.10.15), menu FILE + menu 🔧 strumenti in topbar, "ALL", PRO iridescente (v1.10.19/27).
