# Changelog v0.12.2 (2026-04-06)

## ✨ Nuova Funzionalità: Pannello Keymapping Centralizzato

Introdotta la gestione centralizzata di tutte le scorciatoie di sistema e delle associazioni MIDI/Tastiera, per un controllo totale in tempo reale senza dover ispezionare le clip singolarmente.

### Componenti Aggiunti / Modificati

- **Global Controls (`GlobalControls.tsx`)**: Nuovo pulsante `Keyboard` posizionato accanto ai controlli MIDI originari, usato per l'accesso istantaneo alla dashboard di assegnazione.
- **Keymapping Dashboard (`KeymappingModal.tsx`)**: Nuova interfaccia tabellare che aggrega:
  - **Global Binds**: Master Volume, Stop All.
  - **Clip Binds**: Lista di tutte cliple operative con un `keybind` o `midiBind` attivo.
  - **Quick Clear & Re-Bind**: Possibilità di rimuovere (Clear) le sovrapposizioni e riassegnare rapidamente nuovi input.

### Gestione Configurazione

- La Roadmap `ROADMAP.md` è stata aggiornata, con l'architettura a griglia `Layout Regia 5.0` contrassegnata formalmente come completata.
