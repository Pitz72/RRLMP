# Changelog — Runtime Live Machine Pro v1.2.0

**Data:** 2026-04-11  
**Tipo:** Minor Release — Recording, UI, Bugfix

---

## Riepilogo

v1.2.0 consolida le funzionalità introdotte in v1.1.x con una serie di fix critici, miglioramenti UX e un redesign del pannello impostazioni. Partendo da v1.1.1 (Session Recording + Mic-in-Mix introdotto da v1.1.0), questa release porta il sistema recording a funzionamento completo e ridisegna l'intera interfaccia di configurazione.

---

## ✨ Novità

### Recording Export Modal (v1.1.4)
Nuova finestra di esportazione post-registrazione. Sostituisce i vecchi pulsanti WAV/WEBM con un dialog completo:
- **5 formati:** WAV, FLAC, MP3, OGG, WEBM
- **Bit depth** per WAV/FLAC: 16-bit, 24-bit, 32-bit float
- **Bitrate** per MP3/OGG/WEBM: 128 / 192 / 256 / 320 kbps
- Flusso: Stop → Esporta → Scelta formato/qualità → Dialog di sistema → Toast successo → REC idle

### Settings Modal Redesign (v1.1.5)
Il pannello impostazioni è stato completamente riorganizzato in 5 tab tematiche (prima erano 3 con contenuti mischiati):
- **⚙️ Generali** — Lingua interfaccia
- **🎚️ Audio & Mix** — Output device, ducking, transizioni
- **🎙️ Microfono** — Smart Mic, Canale Mix, Feedback Warning
- **⏺ Registrazione** — Session Recording info e formato predefinito
- **⛓️ Master Chain** — HPF, Compressore, Limiter
- Dimensioni fisse: 75vw × 80vh, max 960px

### Colori Clip Dinamici (v1.1.6)
Le clip ora seguono in tempo reale il colore corrente della colonna parent:
- **Idle:** versione schiarita del colore colonna (65% blend verso bianco)
- **Playing:** colore pieno e acceso
- `clip.customColor` (scelta esplicita per singola clip) mantiene la priorità assoluta

## 🐛 Bug Corretti

### Recording: Fix Critico Architettura IPC (v1.1.3)
Tre bug che impedivano il funzionamento del recording:
1. **Type mismatch:** `AudioRecorder.stop()` ritornava `ArrayBuffer` ma veniva assegnato a `tempPath: string` — ora viene prima salvato su disco via IPC `save-recording-buffer` per ottenere il path reale.
2. **Preload incompleto:** `convertRecording` e `deleteTempRecording` non erano esposti → crash silenzioso.
3. **Argomento mancante:** `showSaveDialogRecording` non passava il parametro `format` all'IPC → dialog senza filtro estensione.

## 🔧 Miglioramenti

### Feedback Warning Microfono — Dismissable (v1.1.2)
Il box di avviso feedback acustico (fischio) può ora essere soppresso con una checkbox "Ho capito. Uso cuffie o un mixer professionale." La scelta è persistita in localStorage. Un link "Rileggi avviso" riporta il warning completo se necessario. Utile per chi usa Rødecaster o altri mixer professionali con routing interno (nessun rischio feedback reale).
