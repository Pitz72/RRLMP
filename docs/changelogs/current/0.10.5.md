# Changelog v0.10.5 (2026-04-06)

## 🏗️ Transizione Main-Side-Heavy: Step 1 (Backend Node.js)
Il primo step della transizione strutturale v0.11.0 è stato completato. È stato sviluppato il motore di analisi audio a livello server nel processo Main, preparando il terreno per alleggerire il Renderer.

### ✨ Novità Architetturali

- **Nuovo Modulo `AudioProcessor` (`src/main/AudioProcessor.ts`)**:
  - Implementato `extractMetadata()` che sfrutta **`music-metadata`** per l'estrazione ultra rapida della durata (duration), canali e bitrate, superando la necessità di decodificare il file in frontend.
  - Implementato `generateWaveformData()` sfruttando **FFmpeg** in child-process. Il motore normalizza l'audio con filtro `aresample=8000` estraendo in streaming chunk PCM raw (Peak Data) che vengono poi decodificati lato Node.js per generare un pacchetto dati ottimizzato per il rendering della Waveform.

- **Nuovi endpoint IPC (`src/main/index.ts`)**:
  - `get-audio-metadata`: Handler asincrono per richiedere le info generiche della traccia.
  - `get-waveform-data`: Handler asincrono per lanciare la generazione dei Peak array.

### 🐛 Fix e Allineamenti
- Bypassati i controlli rigidi di Type per la libreria `ffprobe-static` data l'assenza temporanea del layer @types nativo.
