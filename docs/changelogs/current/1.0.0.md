## Riepilogo cumulativo — Tutte le funzionalità v1.0.0

### Audio Engine
- Streaming `media://` — nessun caricamento in RAM
- FFmpeg main-side: silence detection, waveform, metadata ID3
- Transition engine per tutte le colonne: Crossfade, Segue, Gapless
- Auto-Silence Detection al drop in PRE-SHOW
- Ducking sidechain (source/target per clip)
- **Smart Mic Auto-Ducking** — hardware mic monitoring via Web Audio API
- Master Chain broadcast-grade: HPF + Compressore + Limiter brickwall
- Output device hot-switch
- Emergency Stop (tasto Escape globale)
- Preview Transizione con Stop button protetto da hasPlayed

### Board & Workflow
- 5 colonne fisse: Assets, Music, Voice, SFX, PRE-SHOW
- ARM button microfono + mini VU meter 8 barre in header
- Column Color Picker (30 colori, persistito nel .lmp)
- INTRO countdown e OUTRO pre-cue in tempo reale su ClipCard
- UP NEXT badge dinamico
- FADE OUT badge durante transizioni
- Drop indicator luminoso durante drag da OS
- Timer On Air + Orologio digitale in header
- NoteBoard auto-show/hide per note di regia
- Toast notification system (no alert bloccanti)
- ConfirmDialog Promise-based (audio continua durante la scelta)
- MIDI Learn + keybinding per clip
- Import playlist M3U/M3U8 → PRE-SHOW con auto-silence detection
- Export self-contained (copia tutti i file audio con il progetto)
- Auto-backup ogni 5 minuti
- LMP Integrity Check al caricamento
- Waveform Editor interattivo (4 handle: TrimStart, TrimEnd, Intro, Outro)

### Internazionalizzazione
- 8 lingue complete (EN, IT, FR, DE, ES, PT, RU, ZH)
- Selezione immediata da WelcomeScreen e da Settings → tab Lingua
- Persistita in localStorage

## Note tecniche

- `fallbackLng: 'en'` in i18next garantisce che chiavi eventualmente mancanti in future lingue non causino errori UI
- I file locale sono importati staticamente in `i18n.ts` — nessun caricamento lazy (bundle size accettabile per un'app desktop)
- Le traduzioni dei termini tecnici broadcast (ducking, crossfade, segue, gapless) sono state mantenute in inglese dove sono termini standard del settore
