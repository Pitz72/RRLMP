# Changelog v0.14.5 (2026-04-07)

## ⏱️ Feature Release: Timer On Air / Elapsed (§4.4)

Questa release implementa il punto **§4.4** della VISION.md ("Timer On Air / Elapsed", priorità 🟠 ALTA). Un counter `ON AIR HH:MM:SS` nell'header dell'applicazione misura il tempo trascorso dall'inizio della sessione di messa in onda. Parte al primo play, si azzera allo Stop All.

---

## 🔍 Funzionamento

### Ciclo di vita del timer

| Evento | Effetto sul timer |
|--------|------------------|
| Prima clip avviata (da idle) | Timer parte da `00:00:00` |
| Ulteriori clip avviate | Nessun effetto — il timer continua |
| Clip singola stoppata | Nessun effetto — il timer continua |
| `stopAll()` / Emergency Stop (Escape) | Timer si azzera → `--:--:--` |
| Nuovo progetto / ricarica | Timer si azzera tramite `stopAll()` |

Il timer misura il **tempo di sessione on-air**, non il tempo di singola clip. Rimane attivo finché c'è anche solo una clip in riproduzione.

### Stato idle

Quando non c'è nulla in riproduzione, il timer mostra `ON AIR --:--:--` in grigio scuro (`text-zinc-700`) senza dot rosso.

### Stato attivo

Quando almeno una clip è in riproduzione, il timer mostra:
- Dot rosso pulsante (`animate-pulse`) — indicatore visivo "live"
- Testo rosso (`text-red-400`) con sfondo rosso scuro (`bg-red-950/40`)
- Bordo rosso sottile con glow sottile
- Formato: `ON AIR 01:23:45`

## 🏗️ Architettura Store

### Campo aggiunto ad `AudioStore`
```typescript
onAirStartTime: number | null; // timestamp ms, null quando idle
```

### Avvio in `playClip()` (set atom)
```typescript
set((state) => {
    const wasIdle = Object.keys(state.activeClips).length === 0;
    return {
        activeClips: { ...state.activeClips, [freshClip.id]: { ... } },
        onAirStartTime: wasIdle ? Date.now() : state.onAirStartTime
    };
});
```

### Reset in `stopAll()`
```typescript
return { activeClips: {}, suppressedClips: {}, onAirStartTime: null };
```

### Logica del componente
```typescript
useEffect(() => {
    if (!onAirStartTime) { setElapsed(0); return; }
    setElapsed(Date.now() - onAirStartTime); // sync immediato
    const interval = setInterval(() => {
        setElapsed(Date.now() - onAirStartTime);
    }, 1000);
    return () => clearInterval(interval);
}, [onAirStartTime]);
```

## 🎨 Design

Il timer è collocato nell'header a destra, **prima** del `DigitalClock` (orologio di sistema). La lettura naturale è: `[ON AIR 00:12:34] [14:35:22]` — prima il tempo di sessione, poi l'ora corrente.

Il glow rosso è sottile: visibile in condizioni normali ma non abbagliante in studio buio.
