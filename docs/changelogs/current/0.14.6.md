## ⚡ Feedback Visivo Auto-Silence (§2.1)

### Problema risolto

Quando una clip veniva droppata nella colonna PRE-SHOW, `detectSilence()` girava in background via IPC FFmpeg per 1-5 secondi senza alcun feedback visivo. L'utente non sapeva se il trim fosse in corso o già completato.

### Soluzione

**Flag runtime `isAnalyzing?: boolean`** su `AudioClip` (non persistito nel `.lmp`).

Ciclo di vita:
1. Drop nella colonna PRE-SHOW → `updateClip(..., { isAnalyzing: true })`
2. `detectSilence()` gira in background
3. Risultato ricevuto (successo o errore) → `updateClip(..., { isAnalyzing: false })`

**Badge ClipCard:** badge ambra pulsante `⚡ TRIM…` con dot `animate-ping` finché `isAnalyzing` è true.

```tsx
{clip.isAnalyzing && (
    <span className="text-[9px] bg-amber-500/20 text-amber-400 border border-amber-500/40 px-1.5 rounded font-bold flex items-center gap-1">
        <span className="inline-block w-2 h-2 rounded-full bg-amber-400 animate-ping opacity-75" />
        TRIM…
    </span>
)}
```

## 🎹 KeymappingModal Potenziato (§2.1)

### Modifiche

Il pannello `KeymappingModal` è stato riscritto con queste migliorie:

1. **Raggruppamento per colonna** — le clip sono ora organizzate sotto header colorati per colonna (`— NOME COLONNA (N clip) —`), con il colore specifico della colonna. Prima erano in lista piatta.

2. **Sezione Azioni Globali di Sistema** — header separato per le azioni globali. Aggiunta la voce **"Emergency Stop (tutti i player)"** con keybind fisso `Escape` (non modificabile, badge grigio) e MIDI disabilitato.

3. **Dot colorato per clip** — ogni clip mostra un pallino del proprio `customColor || colonna.color` accanto al nome.

4. **Colonne vuote** — se una colonna non ha clip, mostra "Nessuna clip in questa colonna" invece di collassare.

5. **Tipo badge** — "Sistema" per le voci fisse, "Globale" per le azioni MIDI, "Clip" per le clip.

## 📋 NoteBoard — Note Regia a Schermo durante il Playback

Le note scritte nella tab "Notes / Script" del ClipSettingsModal ora vengono mostrate in un **pannello fisso in fondo alla schermata** mentre la clip è in riproduzione.

### Comportamento

- **Nessuna clip in play** (o clip senza note) → il pannello è invisibile e non occupa spazio
- **Clip con note in play** → il pannello appare automaticamente con:
  - Header colorato con il colore della clip + nome clip
  - Testo note in font monospace, leggibile, scrollabile se lungo
  - Rispetta interruzioni di riga e formattazione esatta dell'input
- Il pannello si chiude da solo al termine della clip

### File modificati

| File | Modifica |
|------|----------|
| `src/renderer/src/components/ui/NoteBoard.tsx` | Nuovo componente: legge `activeClips` + `columns`, mostra note della prima clip in play con note |
| `src/renderer/src/App.tsx` | Import e inserimento `<NoteBoard />` sotto `<MainGrid />` nel layout |

## 🐛 Hotfix: Crash Auto-Trim nel ClipSettingsModal

### Problema

Il pulsante **Auto-Trim** nella tab Trim del `ClipSettingsModal` causava un crash devastante (schermo bianco, app chiudibile solo da Task Manager). La causa era una vecchia implementazione renderer-side pre-architettura Main-Side-Heavy:

```ts
// CODICE RIMOSSO — caricava l'intero file audio in memoria Chromium
const response = await fetch(toFileUrl(clip.path));
const arrayBuffer = await response.arrayBuffer();       // OOM su file grandi
const audioBuffer = await audioCtx.decodeAudioData(arrayBuffer);
// ... scan manuale dei campioni PCM nel renderer
```

`decodeAudioData` su file audio grandi (>100MB) esauriva la memoria del processo renderer Chromium → crash non recuperabile.

### Fix

Sostituita la logica renderer-side con la chiamata IPC già esistente (`window.electron.detectSilence`), identica a quella usata in `MainGrid.tsx` per l'auto-silence al drop in PRE-SHOW. FFmpeg gira nel main process (Node.js), il renderer non tocca più i dati PCM grezzi.

```ts
// FIX — FFmpeg via IPC, zero ArrayBuffer nel renderer
const result = await window.electron.detectSilence(clip.path);
```

| File | Modifica |
|------|----------|
| `src/renderer/src/components/modals/ClipSettingsModal.tsx` | `detectSilence()` riscritta: rimossa logica fetch+decodeAudioData, sostituita con `window.electron.detectSilence()` IPC |
| `src/renderer/src/components/modals/ClipSettingsModal.tsx` | Rimosso import inutilizzato `toFileUrl` da `pathUtils` |
