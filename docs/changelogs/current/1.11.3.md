# v1.11.3 — Controllo Remoto: ritorno definitivo al browser (via l'app Android)

**Data:** 2026-07-02

## Contesto — decisione utente

*"Stiamo complicando tutto […] io credo che la primissima idea dell'HTTP e uso via browser da server in LAN sia la cosa migliore, funzionava benissimo e aveva meno problemi di gestione. Al massimo mettiamo un pulsante fullscreen. Torniamo indietro dalla questione Android APK."*

Il modello DEFINITIVO del Controllo Remoto è quindi: **pagina HTTP aperta nel browser del tablet/PC in LAN**, PIN + WebSocket autenticato. Decadono la PWA installabile (richiedeva secure context → il "buco nero" dei certificati) e l'app Android nativa (APK WebView + mDNS, mai testata su hardware) — un intero progetto satellite in meno da mantenere e riallineare.

## Rimosso

- **Cartella `android/`** (guscio WebView Kotlin, v1.9.2) e **workflow `.github/workflows/android.yml`** (build APK in CI, v1.9.3).
- **mDNS/auto-discovery** (`bonjour-service`, v1.9.4): pubblicava `_rrlmp._tcp` per l'app Android; nessun browser lo consuma → dipendenza npm disinstallata, `startMdnsAdvertisement/stopMdnsAdvertisement` eliminati.
- **PWA**: schermo "Installa l'app" (con `beforeinstallprompt`/istruzioni manuali), gestione `?app=1`, `manifest.json`, service worker — via da `remoteControlAssets.ts` e route `/manifest.json`, `/sw.js` via dal server (ora 404).

## Aggiunto

- **Pulsante "⛶ Schermo intero"** nella pagina remota (richiesta esplicita): fisso in alto a destra, sempre raggiungibile (schermata PIN e controlli), toggle via Fullscreen API con label aggiornata sugli eventi `fullscreenchange`; nascosto dove l'API non esiste (es. iPhone). Sostituisce lo scopo dell'installazione PWA (niente barra del browser).

## Fixato (residuo trovato in corsa)

- **`GeneralSettingsModal`**: il pulsante "Copia link" costruiva e mostrava l'URL come `https://…` ma il server è HTTP puro da v1.9.1 → il link copiato/inviato al tablet non funzionava. Ora `http://`, e l'hint sul certificato auto-firmato (altro residuo del prototipo HTTPS) è sostituito da istruzioni browser+fullscreen.

## Invariato

Server HTTP porta 8787 opt-in (default OFF), PIN 6 cifre + rate-limiter, WS con whitelist comandi (`stopAll`/`playClip`/`stopClip`), broadcast stato colonna Music. Resta pendente (sessione dedicata, come da roadmap): espansione della pagina remota alle altre colonne + restyling Spectrum + riallineamento alle novità UI (pad FX, colonne nascoste, automix).
