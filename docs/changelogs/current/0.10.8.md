# Changelog v0.10.8 (2026-04-06)

## 🏗️ Transizione Main-Side-Heavy: Step 4 (Ottimizzazione Protocollo Streaming)
Intervento mirato alla robustezza del protocollo interno dedicato alla riproduzione di base dei file audio, che previene disconnessioni o colli di bottiglia sotto stress o su NAS lenti.

### ✨ Novità Architetturali

- **Ottimizzazione I/O Custom Protocol (`media://`)**:
  - Il buffer di lettura (`highWaterMark`) utilizzato da Node.js (`fs.createReadStream`) in `src/main/index.ts` è stato incrementato a 1MB per chunk, invece dei precedenti 128KB.
  - Questo previene fenomeni di disk-thrashing estremo quando The Waveform Editor tenta di leggere il backend e quando il player riproduce file ad alti bitrate, salvaguardando l'SSD dell'utente.
  - Aggiunti event listener per intercettare esplicitamente errori di reading e pipe-break, in modo da avere log parlanti lato Node.js se un disco rimovibile o di rete viene scollegato durante la riproduzione in onda.
