# v1.10.10 — Pad FX: tasto destro apre le impostazioni + il colore riempie il pad

**Data:** 2026-07-02

Versione **patch** — riscontri dev dell'utente sulla jingle machine (2/3).

## Cosa cambia (`FxPadOverlay.tsx`)

1. **Tasto destro sulla cella = impostazioni clip.** Prima l'unico accesso era la ⚙ su hover ("devo premere il pulsantino accanto alla X"): ora `onContextMenu` apre la stessa modale, col solito `blur()` anti-retrigger (v1.10.3). La ⚙ resta come indicatore visivo dell'azione.
2. **Il colore assegnato riempie il pad.** Assegnando un colore dalle impostazioni clip (`customColor`), la cella si tinge (sfondo ~18% + bordo ~60% del colore). Solo il `customColor` esplicito: il `color` di colonna (uguale per tutti gli FX) non tinge nulla, così i pad senza colore restano neutri. Gli stati speciali hanno priorità e restano leggibili: in onda (verde), file mancante (rosso), MIDI Learn (cyan).

## Test e stabilità

- Typecheck renderer: **0 errori**. Vitest **99/99**. Solo presentazione + un nuovo entry point alla modale esistente.
