# v1.15.33 — Runtime Live Machine Pro becomes free software

**Type:** source opening · **Date:** 2026-09-13

## Opening the source

Runtime Live Machine Pro is **no longer for sale**: from this version it is **free software**, released under the **MIT licence**. You can use, copy, modify and redistribute it freely, and the source code is public at **github.com/Pitz72/RRLMP**.

It was born in January 2026 as a Runtime Radio tool for running live shows without a producer at your side; from now on it is maintained for fixes, and anyone can propose improvements.

## Updates come from a new address

Up to 1.15.32, updates were downloaded from a separate repository, **Ecosystem-Runtime/RRLMP-Releases**. From this version they come from the project’s releases, **github.com/Pitz72/RRLMP/releases**.

**You don’t need to do anything:** once this update is installed, the program already knows where to look for the next ones. This same version is published in both places precisely to bring along everyone who already has the program installed.

## macOS: no more official installer

The `.dmg` package for macOS is no longer published. If you have a Mac, you can **build the program from source**: instructions are in the User Manual (section 2.3) and in the project’s `CONTRIBUTING.md` file. Windows and Linux (AppImage and `.deb`) keep their packages.

## What you see in the application

- **Welcome screen** — at the bottom you’ll find the licence, the author and the credit to the language models the program was written with.
- **Info panel** (Tools menu) — new **“The project”** section: licence, author, the full list of models used (Gemini 3.0 and 3.1; Claude Sonnet 4.6, Opus 4.7, Opus 4.8, Sonnet 5, Opus 5 and Fable 5) and three buttons: **Source code**, **Contact** and **Buy me a coffee**.
- **User Manual button** — opens the PDF from the project repository.
- **Quick guide** — updated with what’s new, the licence and the macOS instructions.

## Safer external links

The application opens in the browser only **https** addresses from a closed list of project sites (GitHub, the Runtime Radio sites and the donation page). Before, it accepted any web address requested by the interface.

## User manual

The manual, in Italian and English, is aligned with this version and carries the MIT licence instead of “All rights reserved”, with the credit to the models and the address of the code. Chapter 2 explains where to download the installers (the Releases page on GitHub) and how to build on macOS.

## Also included, if you are updating from an earlier version

If you are updating from a version earlier than 1.15.32, this update also brings you everything below.

**v1.15.32 — The app speaks Italian and English**
- The interface, quick guide, manual and remote control page are in **Italian and English**; French, German, Spanish, Portuguese, Russian and Chinese have been removed. If you used one of those languages, the app restarts in English.
- The **welcome screen** is more compact: the language is picked from a drop-down in the top-right corner.
- **Manual** updated with new screenshots and chapters on the ON AIR banner, Smart Mic, the F1–F6 keys and the other new features.

**v1.15.31 — A steady board while on air**
- The **ON AIR** banner is always there: with nothing playing it shows OFF AIR in muted colours; when a track starts it lights up at exactly the same size, without pushing the columns down.
- The timer, the OUTRO IN warning and the UP NEXT box have a fixed footprint; between two tracks in a sequence the banner holds the track that just ended for a moment instead of flashing.
- On clip cards, badges, timer and title no longer move when UP NEXT, FADE OUT, TRIM or the INTRO/OUTRO cues appear.

**Audio and playback**
- **v1.15.16 — The end-of-track fade is no longer cancelled.** Firing or stopping a voice, jingle or effect while a track was fading brought it back to full volume, then cut it off abruptly at the end of the file.
- **v1.15.20 — Tracks on network folders actually play.** Clips on a NAS or shared folder (`\\server\...`) looked normal but would not start.
- **v1.15.24 — Inconsistent trims no longer break playback.** A trim longer than the track left the clip with zero length, and a looping clip restarted endlessly; such trims are now reset when the project opens.
- **v1.15.30 — Smart Mic is back.** With the microphone armed, the music dips on its own when you speak. Designed for a USB microphone plugged straight into the computer: with USB mixers the input carries the whole programme and the detector triggers by itself (the warning is written in the Microphone tab).

**Projects, saving and export**
- **v1.15.17 — Export no longer deletes files that don't belong to it.** An existing `audio/` folder next to the project was emptied on the first export; now only the archive folder created by RRLMP is cleaned.
- **v1.15.18 — The project no longer marks itself as "modified".** The automatic analyses on opening (silence, loudness, BPM, tags) no longer turn on the unsaved-changes indicator.
- **v1.15.19 — "Restart and install" no longer loses the open project.** With unsaved changes, the app now asks before installing the update.
- **v1.15.22 — Saving no longer hides missing-file warnings.** After "Save as", clips whose file was unreachable went back to looking normal.

**Recording**
- **v1.15.21 — Recording no longer hangs if the drive fails.** An unplugged USB stick or a full disk left the app waiting forever; now the recording closes and keeps what was captured.

**Remote control**
- **v1.15.23 — Stronger PIN and third-party connections refused.** The PIN is generated with the system's cryptographic generator; connections opened by web pages from other sites are refused.
- **v1.15.25 — Remote control warns when it fails to start.** With the port already in use, the switch stayed on with no server running; now it turns back off and shows the reason.

**Keyboard and interface**
- **v1.15.26 — Function keys follow the columns you see.** F1, F2, … follow the grid order and remap when you hide a column. With the default layout F6 is PRE-SHOW, which could not be reached from the keyboard before.
- **v1.15.27 — Refinements.** Among others: Ctrl+Z and Delete no longer act on the rundown while a window is open (ESC always works); intro and outro markers realign after seeking back.

**Maintenance**
- **v1.15.28** — Removed the internal leftovers of the old "Stacco" behaviour from the audio engine, with no change in behaviour.
- **v1.15.29** — Updated the vulnerable library used by the auto-updater to read information about new versions.
