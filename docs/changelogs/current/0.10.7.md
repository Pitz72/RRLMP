# Changelog v0.10.7 (2026-04-06)

## 🏗️ Transizione Main-Side-Heavy: Step 3 (Waveform Proxy Frontend)
Questo è un momento cardine. Il `WaveformEditor` nel Renderer è stato riattivato graficamente, ma questa volta utilizzando i Peak Data generati in background dal Main Process, bypassando le Web Audio API sui file originali pesanti.

### ✨ Novità Architetturali

- **Riattivazione Waveform (`src/renderer/src/components/ui/WaveformEditor.tsx`)**:
  - Implementato `useEffect` che richiede asincronamente i picchi via IPC (`window.electron.getWaveformData`).
  - Animazione e notifica visuale durante il calcolo dell'array in backend tramite Node.js.
  - Sostituito il rendering "fake" generato casualmente con la mappatura reale dei dati raccolti dal proxy, scalati per visibilità e senza pesare oltre 1MB nella RAM del client.
  - Confermata l'effettiva invulnerabilità al noto crash `0xC0000005`, poiché Chromium non tocca l'infrastruttura di decoding dei metadati.
