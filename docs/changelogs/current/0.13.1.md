# Changelog v0.13.1 (2026-04-06)

## Bugfix Critici

- **Protocollo `media://`**: Corretto bug nel parsing degli URL che causava il fallimento del caricamento di file con caratteri speciali (come apostrofi o spazi) su sistemi Windows.
- **Silence Detection**: Ripristinata la funzionalità di scansione automatica del silenzio, che era interrotta a causa del malfunzionamento del protocollo media.
- **Update Checker**: Migliorata la gestione degli errori nel controllo aggiornamenti. Il sistema ora ignora correttamente le risposte non-JSON (come le pagine di errore HTML 404), evitando crash silenziosi o errori di sintassi nei log.

## Miglioramenti

- **Robustezza URI**: Implementata una gestione centralizzata e coerente degli URL tramite `toFileUrl` in tutti i moduli del Renderer.
- **Main Process Protocol**: Il gestore del protocollo `media:` è ora più tollerante verso le diverse varianti di slash passate da Chromium.
