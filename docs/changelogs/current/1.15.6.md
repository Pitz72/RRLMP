# v1.15.6 — Localizzazione integrale (i18n al 100% nelle 8 lingue)

**Data:** 2026-07-03

## Contesto

Audit totale della localizzazione richiesto dall'utente dopo la remediation
i18n della v1.11.5 (248 chiavi in 16 componenti): individuare OGNI punto in
cui il software non passava ancora per i18n e portare la traduzione integrale
in tutte e 8 le lingue (it/en/fr/de/es/pt/ru/zh). Superficie i18n:
**312 → 461 chiavi per lingua**, parità verificata a script (0 chiavi mancanti,
placeholder `{{…}}` coerenti tra lingue).

## Renderer — componenti

- **ClipSettingsModal** (il buco più grosso): ~30 etichette hardcoded in
  inglese (Clip Name, Color Label, Volume Gain, Global Keybind, Playback
  Behavior, Loop Playback, Autoplay Next, Smooth Fades, Manual Inputs,
  Trim/Intro/Outro, DELETE CLIP / Cancel / SAVE CHANGES…) + 6 toast in
  italiano fisso (Auto-Trim, outro incoerente, analisi silenzio).
- **KeymappingModal**: interamente cablato (titolo, blocco istruzioni con
  markup via `<Trans>` — pattern nuovo nel progetto —, intestazioni tabella,
  badge Sistema/Globale/Clip, conferma conflitto tasto, LISTENING, Learn MIDI,
  Chiudi Pannello, nomi azioni globali).
- **MidiSimulatorModal**: titolo, sottotitolo, campi, Invia messaggio,
  Ultimo inviato, nota a piè con `<Trans>`.
- **ExportProgressModal**: titolo e contatore file.
- **DebugOverlay**: etichette statiche (STATE INSPECTOR, Audio Monitor,
  Omologazione, Active Clips, LOG STREAM, COPY/CLEAR, "non misurata").
  I messaggi di log restano non tradotti: sono diagnostica per il supporto.
- **ErrorBoundary** (classe → `i18n.t` diretto): fallback di zona, Riprova,
  toast errori asincroni.
- **Badge ClipCard**: STACCO/LOOP/NEXT/UP NEXT/TRIM…/FADE OUT/PRIORITY +
  tooltip BPM. **NowPlayingHero**: ON AIR / IN ONDA / OFF AIR / OUTRO IN /
  UP NEXT. **ColumnHeader**: badge END + tag tipo colonna.
- **WaveformEditor**: Zoom In/Out, Stato, pulsanti marker.
  **RecordingButton**: REC / Conversione… **MainGrid**: "Drop Audio Here".
  **WelcomeScreen**: tooltip manuale. **AboutModal**: "Controlla
  aggiornamenti ora". **GlobalControls**: tutti i toast (salvataggio, M3U,
  export/sync archivio), badge FILE/On Mix/Mic Vol, "Auto-saved",
  tooltip STOP ALL. **FxPadOverlay**: conferme rimozione/ripristino, titolo.
- **App.tsx**: dialoghi di chiusura/apertura con modifiche non salvate
  (riusano le chiavi `modal.dialog.*` già presenti nei JSON ma mai cablate),
  conferma eliminazione multipla, tutti i toast di load/save.

## Renderer — store

- `useConfirmStore`: default Conferma/Annulla risolti a runtime via `i18n.t`.
- `useAudioStore`: i 3 reason dell'automix che finiscono nei toast.
- `useProjectStore`: `DEFAULT_COLUMNS` → **funzione `getDefaultColumns()`** —
  i titoli di default si localizzano ALLA CREAZIONE del progetto. Il titolo
  resta dato di progetto (.lmp): cambio lingua non tocca progetti esistenti
  né titoli rinominati dall'utente. Rimosso da ColumnHeader il lookup
  `t('columns.'+id)` con chiave sbagliata (avrebbe sovrascritto le rinomine
  se "riparato"). Corrette le chiavi `columns.*` di it.json che avevano
  valori inglesi; aggiunte `columns.jingle`/`columns.promo`.

## Processo main (novità architetturale)

- Nuovo **`src/main/i18nMain.ts`**: dizionario piatto a 8 lingue + `tMain()`.
  La lingua arriva dal renderer via IPC **`i18n:set-language`** (hook
  `languageChanged` in `i18n.ts`, `setAppLanguage` nel preload) — copre avvio
  e cambio lingua dalle Impostazioni.
- Localizzati: tutti i dialog nativi (Salva/Carica Progetto, Importa M3U,
  cartella export, salvataggio registrazione, Playout Log — titoli e filtri),
  il close-dialog legacy, e gli errori IPC che il renderer mostra nei toast
  (.lmp corrotto, struttura/percorso progetto, manifest default-sfx,
  conversione registrazione, "File non trovato" e affini in AudioProcessor).

## Pagina web Controllo Remoto

Era interamente in italiano fisso. Ora ha un dizionario embedded a 8 lingue
(`RC_I18N`) con rilevamento **`navigator.language` del browser del
dispositivo remoto** (scelta deliberata: il tablet può avere una lingua
diversa dalla regia). Coperti: sottotitolo PIN, Connetti, stati
(Connesso/Disconnesso/PIN errato/rate-limit/verifica/errore rete),
Play/Stop per clip, schermo intero, `<title>` e `lang`. I payload JSON del
server restano codici (mai mostrati direttamente).

## Non tradotto di proposito

Glifi da console a larghezza fissa (FX/MIX/ALL/ARM — i tooltip localizzati
ne veicolano il significato), gergo broadcast invariante (Master Chain, HPF,
Limiter Brickwall, Playout Log, Fade/Trim/BPM/LUFS, Learn MIDI, Note On/Off,
CSV), scorciatoie Ctrl+Z/Y, messaggi `debugLog`/logger.
