# Changelog v0.14.9 (2026-04-07)

## Feature Release: Indicatore Visivo Transizione in Corso

---

## 🔴→⬛ Badge "FADE OUT" sulla ClipCard durante transizioni

### Problema risolto

Quando una transizione Crossfade o Segue era in corso, la clip uscente continuava a sembrare normale sulla ClipCard — nessun indicatore visivo che il fade stesse avvenendo. L'operatore non aveva feedback visivo immediato sullo stato della transizione.

### Implementazione

**Refactoring `transitioningClips`**: il `Set<string>` module-level (non reattivo) è stato sostituito con `fadingClipIds: string[]` nello stato Zustand. Questo permette ai componenti React di sottoscriversi e reagire.

**Badge ClipCard**: quando `fadingClipIds.includes(clip.id)` è true, la card mostra un badge viola pulsante `● FADE OUT`. Scompare automaticamente quando il fade termina e `stopClip` viene chiamato.

```tsx
{isFading && (
    <span className="... bg-violet-500/20 text-violet-300 border border-violet-500/40 ... animate-pulse">
        <span className="w-2 h-2 rounded-full bg-violet-400" />
        FADE OUT
    </span>
)}
```

**Ciclo di vita badge**:
1. Transizione avviata (`effectiveType === 'crossfade' | 'segue'`) → `fadingClipIds` include il clipId
2. Fade-out in corso → badge violet pulsante visibile
3. `setTimeout` scade (durata fade + 200ms) → `stopClip` + rimozione da `fadingClipIds`
4. Badge scompare

**Emergency Stop**: `stopAll()` ora resetta anche `fadingClipIds: []`.
