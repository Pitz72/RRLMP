## Fix — PRE-SHOW: rilevamento silenzio automatico

Prima il batch di auto-silenzio al caricamento progetto (`MainGrid.tsx`) copriva **solo la colonna MUSIC**; per la PRE-SHOW il rilevamento avveniva solo al drop di un file o dietro un prompt opt-in nel pulsante "Carica Progetto" → le clip PRE-SHOW **già caricate** (apertura da Welcome / doppio click) non venivano mai analizzate, con transizioni non ottimizzate.

- Aggiunto un batch **automatico** anche per `col-preshow` (identico a MUSIC), che parte a ogni cambio di `currentFilePath`, qualunque sia la via di caricamento.
- Rimosso il prompt ridondante in `GlobalControls.tsx`.

## Note
- Il comportamento di "Termina attività" dalla taskbar di Windows (che bypassa il dialog di salvataggio) **non è un bug** dell'app: è una terminazione forzata del processo che nessuna applicazione può intercettare. La via protetta resta la X / "Chiudi finestra". Lasciato invariato per scelta.
