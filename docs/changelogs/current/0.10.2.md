# Changelog v0.10.2 (2026-04-05)

## 🚑 Hotfix Release 2 (OOM Crash)
Risolto un crash critico (White Screen of Death) che si verificava tentando di aprire l'editor Waveform per file audio di lunga durata (es. 9 minuti).

## 🛠️ Fix Tecnici

### 💥 Risoluzione Crash Memoria/Canvas
- **Problema:** L'impostazione di zoom predefinita della forma d'onda era troppo alta (50 pixel per secondo). Per una clip di 9 minuti (540 secondi), questo generava un Canvas HTML5 largo 27.000 pixel. Superare il limite hardware/GPU del browser mandava in crash l'intero processo di rendering (schermo bianco). Inoltre, il decodificatore WebAudio saturava la RAM.
- **Soluzione 1 (Auto-Fit):** Modificato lo zoom iniziale dell'editor su `AUTO` (0 px/sec). Ora l'onda sonora viene sempre compressa in modo intelligente per rientrare nella larghezza della finestra, eliminando il rischio di crash per file lunghi. 
- **Soluzione 2 (Backend Streaming):** Sostituito il backend di rendering di `wavesurfer.js`. Ora utilizza un elemento `<audio>` HTML5 standard invece di decodificare l'intero file in un AudioBuffer. Questo riduce drasticamente l'utilizzo di memoria RAM durante l'editing visivo e rende l'anteprima di riproduzione istantanea.

## ⚠️ Nota di Revisione (aggiornata in v0.10.7)

Le due soluzioni documentate descrivono la direzione intrapresa, ma il loro stato finale differisce da quanto scritto:

- **Soluzione 1 (Auto-Fit Zoom)**: Il "sistema di zoom AUTO" con `px/sec = 0` non è stato implementato come tale. Non esiste nessuna logica di zoom nel codice finale. Il vero fix fu abbandonare completamente Wavesurfer.js (le sue impostazioni di zoom non sono più rilevanti).

- **Soluzione 2 (Backend Streaming)**: Questa fu la direzione corretta. La migrazione da Wavesurfer a `<audio>` HTML5 è stata completata in v0.10.7, dove il WaveformEditor usa Peak Data pre-generati da FFmpeg nel Main Process — non Wavesurfer con backend diverso, ma un sistema completamente nuovo.

In sintesi: il crash OOM è stato risolto, ma tramite la migrazione architetturale "Main-Side-Heavy" completata in v0.10.4–v0.10.7, non tramite le configurazioni Wavesurfer descritte.
