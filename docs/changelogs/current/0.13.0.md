# Changelog v0.13.0 (2026-04-06)

## Nuove Funzionalità: Continuous-Play & Automation

- **Sistema di Transizioni Intelligenti**: Implementato supporto per `Crossfade`, `Segue` e `Gapless` nella colonna Pre-Show.
- **Configurazione Globale e Locale**: Aggiunta impostazione di transizione predefinita nelle "General Settings" e possibilità di override per singola clip nelle "Clip Settings".
- **Auto-Silence Detection (Pre-Show)**: I file caricati nella colonna Pre-Show vengono ora analizzati automaticamente per rimuovere i silenzi all'inizio e alla fine, garantendo passaggi fluidi tra i brani.
- **Sequencer Avanzato**: Ottimizzata la logica di avvio della clip successiva basata sul tipo di transizione selezionato.

## Miglioramenti Tecnici

- **Refactoring TypeScript**: Eliminazione di numerosi `any` e `@ts-ignore` in tutto il progetto (`MidiManager`, `AudioProcessor`, `index.ts`, `useAudioStore`).
- **Ottimizzazione Mix Bus**: I cambi di output device ora avvengono alla radice dell'Audio Graph (AudioContext sinkId), garantendo stabilità totale durante il passaggio tra schede audio.
- **Waveform Peak Amplification**: Amplificata la visualizzazione dei picchi per una migliore leggibilità dei file con volume basso.
- **LMP Integrity Check**: Diagnostica automatica all'apertura del progetto per segnalare file audio mancanti.
