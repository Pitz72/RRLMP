# v1.9.3 — CI: build APK Android in GitHub Actions

**Data:** 2026-07-01

Versione **patch** (Controllo Remoto Beta, linea 1.9.x). Step 3: workflow CI che compila l'app Android dello step 2 e produce l'APK sideloadabile, senza bisogno di Android Studio in locale.

## Cosa c'è

- **Nuovo workflow `.github/workflows/android.yml`** (solo `workflow_dispatch`, manuale):
  - JDK 17 (Temurin) + Gradle 8.5.
  - `gradle assembleDebug` nella cartella `android/`.
  - Pubblica l'**APK debug-signed** come artifact `rrlmp-remoto-debug-apk` (retention 14 giorni).
- Il **debug signing** è sufficiente per l'uso personale in LAN: l'APK si installa via sideload (abilitare "origini sconosciute" una volta), senza gestire un keystore di release e i relativi secret.

## Come si usa
1. GitHub → repo → Actions → "Build Android APK" → Run workflow.
2. A build finita, scaricare l'artifact `rrlmp-remoto-debug-apk`.
3. Copiare l'APK sul tablet e installarlo (consentire l'installazione da origini sconosciute).
4. Aprire l'app, inserire l'IP del PC in regia (con il Controllo Remoto attivo in Impostazioni), inserire il PIN.

## Note
- La build Android è **indipendente** dalla build Electron (`build.yml`): tocca solo `android/`.
- Questo step verifica anche che il progetto Android dello step 2 compili davvero (non compilabile in locale su questa macchina, priva di SDK Android).
