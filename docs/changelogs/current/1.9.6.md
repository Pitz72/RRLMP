# v1.9.6 — Scrollbar colonne più scura/integrata (UI regia)

**Data:** 2026-07-01

Versione **patch** (linea UI regia in corso, Step 2/4). Solo presentazione.

## Cosa cambia
Scrollbar verticale delle colonne (`.col-body` in `spectrum.css`) ridisegnata per integrarsi meglio sul fondo nero della board:

- Scrollbar custom `::-webkit-scrollbar` (Chromium/Electron): thumb **scuro tinto col colore della colonna** (`color-mix ~20% var(--col-color) + nero`), track invisibile, thumb reso sottile da un bordo trasparente con `background-clip: padding-box`; hover leggermente più chiaro (~42%).
- Aggiunto `scrollbar-width: thin` + `scrollbar-color` anche per Firefox (coerenza cross-engine).
- Rimosse da `MainGrid.tsx` le utility Tailwind `scrollbar-thin scrollbar-thumb-zinc-700` sul `col-body`, ora ridondanti (sostituite dal CSS custom, più scuro e discreto del vecchio zinc-700).
