# Changelog — Runtime Live Machine Pro v1.1.0 (In Progress)

**Data:** 2026-04-11  
**Tipo:** Feature Release — Recording & Live Input

---

## 🎙️ Novità Principali

### 1. Session Recording (Master Mix)
Implementato il sistema di registrazione nativa. Ora è possibile catturare l'intera sessione di broadcast direttamente su disco.
- **Punto di Tap Post-Processing:** La registrazione avviene dopo la Master Chain (HPF + Comp + Limiter), garantendo una qualità identica a quella trasmessa.
- **Formato WebM/Opus:** Audio cristallino a 320kbps con contenitore WebM.
- **Interfaccia Dedicata:** Nuovo pulsante REC nell'header con timer di registrazione e animazione pulsante.
- **Salvataggio Sicuro:** Dialog di sistema per la scelta della destinazione prima dell'inizio della sessione.

### 2. Canale Mix Microfono
Il microfono è ora parte integrante del mix audio di RRLMP.
- **Live Monitoring:** La voce dell'operatore entra nel Master Bus.
- **Integrazione Master Chain:** La voce beneficia opzionalmente del compressore e del limiter broadcast, livellandosi perfettamente con la musica.
- **Bypass Mode:** Possibilità di saltare il processing per chi ha una latenza hardware critica o processori esterni.
- **Slider Header:** Controllo volume microfono immediato nell'header (appare solo quando il mic è ARMATO).

### 3. Miglioramenti UI/UX
- **Settings Modal:** Nuove sezioni per la configurazione della registrazione e del canale microfonico.
- **Feedback Warning:** Avviso visivo nelle impostazioni per prevenire il feedback acustico (larsen) quando il mic è in mix.
- **Recording Store:** Gestione centralizzata dello stato della sessione e dei chunk audio.

---

## 🛠️ Modifiche Tecniche
- Aggiornato `MicManager` per supportare il routing dinamico dei GainNode.
- Implementato `AudioRecorder` (singleton) basato su Web Audio `MediaStreamDestination`.
- Aggiunti nuovi handler IPC nel Main Process per il salvataggio asincrono di grandi ArrayBuffer.
- Esteso `useSettingsStore` per persistere le preferenze di mix del microfono.
