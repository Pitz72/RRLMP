# Changelog v0.16.1 (2026-04-10)

## Feature Release: Column Color Picker · Testo clip tinto · i18n Modali · Dialog Uniformi

---

## 1 — Column Color Picker

Ogni colonna ha ora un piccolo cerchio colorato nella testata (ColumnHeader), a destra del badge tipo. Cliccandoci si apre un selettore con 12 colori predefiniti.

- Campo `customColor?: string` aggiunto all'interfaccia `Column` (persistito nel .lmp)
- Nuova action `setColumnColor(columnId, color)` in `useProjectStore` — marca il progetto come dirty
- Il colore effettivo è `column.customColor || column.color` (il colore base rimane come fallback)
- Pulsante "↺ Ripristina default" visibile solo se il colore è stato modificato
- Chiusura automatica del picker cliccando fuori (listener `mousedown` su `document`)

---

## 2 — Testo clip tinto con il colore della colonna

Le clip in stato idle (non in play) mostrano ora il nome con una versione semi-trasparente del colore della loro colonna (`clip.color + 'aa'` ≈ 67% opacity), invece del grigio piatto `#e4e4e7`.

- Clip in play: colore custom/emerald (invariato)
- Clip idle: tinto con `clip.color` in semi-trasparenza — facile riconoscimento visivo della colonna di appartenenza
- Clip mancanti: rosso (invariato)

---

## 3 — Dialog di chiusura: Salva / Non Salvare / Annulla

Il dialog che appariva alla pressione del tasto X (chiudi finestra) usava prima un dialog nativo Windows. Ora è un dialog completamente custom in stile app, con 3 pulsanti:

- **Annulla** (sinistra, grigio) — non chiude
- **Non Salvare** (centro, rosso) — chiude senza salvare
- **Salva** (destra, verde, autofocus) — salva e chiude

Implementazione tecnica:
- `useConfirmStore` esteso con `threeWayRequest` + `confirmThree()` helper
- `ConfirmDialog.tsx` gestisce entrambi: dialog 2 pulsanti (standard) e dialog 3 pulsanti
- `App.tsx`: `handleCloseIntent` usa `confirmThree()` invece di `window.electron.showCloseDialogI18n`
