# v1.9.8 — Layout regia configurabile (UI regia)

**Data:** 2026-07-01

Versione **patch** (linea UI regia, Step 4/4 — batch completo). Attiva/disattiva le colonne della board.

## Cosa cambia
- Nuova preferenza **globale** `hiddenColumnIds` in `useSettingsStore` (persistita in localStorage con le altre impostazioni; **non** salvata nel `.lmp`) + azione `toggleColumnVisibility(id)`.
- `MainGrid` filtra le colonne nascoste oltre a FX; la board si ridistribuisce da sola (flex-1).
- Nuova sezione **"Layout regia — colonne"** in Impostazioni → Generali: un interruttore Visibile/Nascosta per ogni colonna (con pallino colore). FX escluso (ha il pad dedicato).

## Comportamento
- Nascondere una colonna è **puramente visivo**: le clip **non** vengono eliminate (restano nello store/`.lmp`) e ricompaiono riattivando la colonna.
- Il **motore audio ignora** `hiddenColumnIds`: la **rotazione PRE-SHOW continua a suonare jingle/promo** anche se quelle colonne sono nascoste (`pickRandomFromColumn` legge dal modello dati, non dalla griglia renderizzata). Idem keybind/MIDI, che restano attivi a prescindere dalla visibilità.
- Preferenza globale: vale per tutti i progetti e sopravvive al riavvio.

- Typecheck renderer: **0 errori**. Vitest **94/94**. Nessun impatto su `.lmp` o motore audio.
