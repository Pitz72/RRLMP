# v1.15.9 — Archivio come riferimento, guida scrollabile, svuota colonna, pulizia menu

**Data:** 2026-07-05

## Export: l'archivio audio diventa il riferimento

- Prima, l'export "self-contained" copiava i file in `<cartella-progetto>/audio/` ma **non ripuntava** né il progetto in memoria né il `.lmp` salvato: la cartella `audio/` restava un backup orfano e cancellare i file originali rompeva le clip (`isMissing`).
- Ora, dopo un export riuscito, le clip vengono **ripuntate alla copia in `audio/`** (path assoluto) e il `.lmp` viene ri-salvato. Così è possibile **cancellare i file audio dalla posizione originale** in sicurezza: la sessione e il salvataggio usano la copia archiviata.
- `export-project` (main) restituisce una mappa `id-clip → path`; nuova store action `applyArchivedPaths` + persistenza in `handleExportProject`. Idempotente sui re-export.
- L'operazione **non entra nella cronologia undo** (un undo ripunterebbe agli originali, che potrebbero essere già stati cancellati).
- Limite noto: il riferimento è un path assoluto — spostare la cartella del progetto altrove rompe i riferimenti (portabilità cross-cartella rimandata).

## Menu FILE

- Nuova store action `clearColumn` (con snapshot per l'undo, pulizia della selezione).
