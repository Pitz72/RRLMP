# Changelog Minor Release v0.4

# v0.4.0 - Internal Clip Sorting 🔄

**Data:** 2026-01-30
**Stato:** Feature Release

## Obiettivo
Implementare il riordino delle clip tramite Drag & Drop (interno e tra colonne) preservando il caricamento file nativo dal desktop.

## Nuove Funzionalità

### Internal Clip Sorting
*   Utilizzando `@dnd-kit`, le clip ora possono essere trascinate verticalmente per cambiarne l'ordine.
*   **Cross-Column Dragging:** È possibile spostare una clip da una colonna all'altra.
    *   La clip eredita automaticamente il **Tipo** (es. `music` -> `voice`) e il **Colore** della colonna di destinazione.

### Compatibilità Ibrida
*   Il sistema gestisce simultaneamente due tipi di Drag & Drop:
    1.  **Browser Native DnD:** Per i file trascinati dal desktop (Windows Explorer).
    2.  **Pointer Events (React):** Per lo spostamento delle card interne.

## Dettagli Tecnici
*   **Dipendenze:** Aggiunte `@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`.
*   **Store:** Aggiunta action `moveClip(source, dest, oldIdx, newIdx)` che gestisce la logica immutabile di array splicing.
*   **Componenti:**
    *   `MainGrid.tsx`: Refactoring completo per includere `DndContext` e `SortableContext`.
    *   `SortableClip.tsx`: Nuovo Wrapper per le card esistenti.
