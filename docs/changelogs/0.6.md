# RRLM Director - v0.6.4 Release Log
**Date:** 02/02/2026
**Type:** Stability & UI Refinement

## 🔔 Key Improvements

### 1. Clip Settings Overhaul
The Clip Settings modal has been completely redesigned to handle more options without scrolling issues:
- **New 2-Column Layout:** Settings are split into "Visual & Basic" (Left) and "Behavior & Timing" (Right).
- **Trim Controls:** Added dedicated inputs for `Trim Start` and `Trim End` to precisely control audio playback segments.
- **Improved Inputs:** Numeric inputs for Fade In/Out and Trim have been styled for better visibility.

### 2. Selection Behavior Refinement
- **Play Clean:** Clicking a clip to play it no longer leaves it "selected" (blue ring). The selection is now automatically cleared on play, ensuring a cleaner visual interface during live shows.
- **Multi-Select Preserved:** You can still use `Ctrl+Click` to select multiple clips without playing them (for bulk delete, etc.).

### 3. Debugging Enhancements
- **Extended Log History:** The integrated Debug Logger now retains the last **500 entries** (up from 50), allowing for deeper troubleshooting of long sessions.
- **Unsaved Changes Guard:** The application now triggers a confirmation dialog if you attempt to close the window while there are unsaved changes in the project.

### 4. Technical Fixes
- **Build System:** Resolved build failures related to component nesting and JSX syntax in the settings modal.
- **Performance:** Optimized modal rendering to reduce overlap and layout shifts.

# v0.6.2 - Cue Points (Trim) ✂️

**Data:** 31 Gennaio 2026
**Stato:** Audio Engine Feature

## 1. Cue Points (Non-Destructive Trim)
*   **Start Offset:** Permette di saltare i primi N secondi di un brano (es. silenzio iniziale). La traccia parte immediatamente dal punto stabilito (`trimStart`).
*   **End Cut:** Permette di fermare la traccia N secondi prima della fine reale (es. tagliare applausi o code lunghe).
*   **Logica Intelligente:**
    *   I fade-out e i loop rispettano la nuova durata effettiva.
    *   Il countdown visivo sulla card mostra il tempo rimanente rispetto al nuovo punto di fine.

## UI Updates
*   Nuova sezione **Timing / Cue** nel pannello Edit Clip.
*   Input numerici precisi (step 0.1s) per Start Offset ed End Cut.
*   Tasto **Reset (R)** per azzerare rapidamente i tagli.

## File Modificati
*   `types/index.ts` (Added `trimStart`, `trimEnd`)
*   `engine/StreamPlayer.ts` (Implemented Seek & Monitor Logic)
*   `components/modals/ClipSettingsModal.tsx` (Added Cue Inputs)

# v0.6.0 - Workflow, Tasti & Sicurezza 🎹🛡️

**Data:** 31 Gennaio 2026
**Stato:** Major Improvement

## 1. Tasti Personalizzati (Hotkeys)
*   **Assegna Tasti:** Ora puoi assegnare *qualsiasi* tasto della tastiera (es. `Q`, `Barra Spaziatrice`, `Numpad1`) a una specifica clip.
*   **Come fare:** Apri le impostazioni della clip (tasto destro -> Edit) e clicca nel campo "Trigger Keybind". Premi il tasto desiderato.
*   **Priorità:** Questi tasti hanno la precedenza sui comandi globali.
*   **Toggle:** Premere il tasto a clip ferma la fa partire. Premerlo a clip attiva la ferma.

## 2. Protezione "Salvataggio Dati"
*   **Unsaved Warning:** Se provi a chiudere il programma con modifiche non salvate, verrai avvisato per evitare di perdere il lavoro.
*   **Indicatore Visivo:** Il pulsante di salvataggio diventa Giallo/Ambra se ci sono modifiche in sospeso.

## 3. Miglioramenti Debug
*   **Nuova Combo:** Per aprire il debug overlay ora serve `Ctrl + Shift + D` (era "0", troppo facile da premere per sbaglio).
*   **Copia Log:** Aggiunto pulsante "COPY" per copiare l'intero log negli appunti.

## 4. UI & Polish
*   Migliorata l'interfaccia dei pulsanti di persistenza (Salva/Carica).
